# v0.19.5 · 命令失败清理与架构优化

本版交付第四批代码质量与架构优化：修复命令失败后的锁残留，统一命令执行生命周期，消除核心循环依赖并加入持续结构检查。[实现 PR #120](https://github.com/wukongnotnull/wukong-animation/pull/120) · [跟踪 #113](https://github.com/wukongnotnull/wukong-animation/issues/113)

## 改了什么

- **命令失败后正常释放锁**：例如 `signoff --step 999` 的受控错误现在经过清理再返回；保留恢复记录，不删除其他命令持有的锁。异步失败和输出回调异常也有回归覆盖。
- **统一命令保护与职责**：22 个命令的预检、锁和恢复登记由单一目录管理，处理器按六组职责拆分，保持参数、输出及 0/1/2 退出码。
- **消除循环并保护来源证据**：提取共享工程上下文、交付输入、QC 配置及参数解析，保留旧导出；QC 生产者和校验者共用来源签名，移动实现纳入指纹。
- **自动阻止结构回退**：架构检查拒绝循环、反向依赖、缺失目标及未登记的动态加载，接入 lint 和 Node 20 三平台 CI。新增 Acorn 仅供仓库开发检查，不进入安装包。
