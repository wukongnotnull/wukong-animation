# 工作台宽表预览

## 问题与目标

分镜稿的十列表格被文档宽度上限和表格最小宽度同时约束。即使右侧预览还有空间，「人声」「音效」等列也可能落在可见范围之外。宽表应使用预览区提供的宽度，允许内容换行以显示最后一列。

## 布局

- 排版预览出现七列及以上的表格时，文档铺满预览区，仅保留内外边距。
- 桌面宽表按可用空间分配列宽，长链接和文字在单元格内换行。分镜表给镜号、景别等短字段较窄的列，给画面和运镜较宽的列，人声、音效等字段各自有独立空间。表格在可用宽度不足时仍可在内部滚动。
- 普通文档和原文模式保留阅读宽度。移动端沿用逐行显示字段的样式。

## 验收

在 Chromium 的 1414px 窗口复现十列分镜，收起审阅栏后文档铺满预览内容区，最右两列无须横向滚动即可看到。展开审阅栏后仍可查看全部列。另检查普通剧本、原文模式和 390px 下的完整字段。
