# 开拍或继续一支动画短片

先读取同一插件内的 `../director/SKILL.md`，按其中的 15 道工序和 12 个审片节点制作。故事取自用户当前消息；没有故事或主题时先询问，不猜测用户已经签批。

## 定位引擎与工程

本文件位于 `<插件根目录>/skills/film/SKILL.md`。先取得**当前加载的本文件所在目录的真实路径**，再上移两级目录，得到插件根目录；引擎是其中的 `engine/bin/wka.mjs`。不要依赖宿主的插件路径环境变量，不要写死源码仓库路径或缓存版本。

确认当前工作目录是用户要存放作品的目录。如果当前目录位于插件安装目录或缓存内，先让用户指定工程目录；没有本地终端或文件访问能力时，说明需要切换到桌面本地执行环境。

在用户工程目录下依次运行（把示例中的 `<插件根目录>` 替换成上面解析出的绝对路径，路径保留引号）：

```bash
node "<插件根目录>/engine/bin/wka.mjs" check
```

`check` 返回非零时停止开拍，引导用户运行本插件的 `setup` skill（可以说「用 wukong-animation 检查并配置环境」）；不要继续初始化或渲染。通过后再运行：

```bash
node "<插件根目录>/engine/bin/wka.mjs" init-project
node "<插件根目录>/engine/bin/wka.mjs" status
```

如果有在制的片子，先询问用户恢复哪支或新建。选择卡片使用宿主实际提供的提问工具；不可用时用编号选项提问，等待明确回复。制作简报、画风和每个审片节点的签批仍按 director 执行，不能把开拍请求当成后续节点的批准。

制作简报使用提问卡片一次只问一个问题，收到用户回答后再问下一题；不能一轮提交多个问题，也不把多个决定塞进同一道题。没有可用卡片工具时，文字提问仍一次一问。
