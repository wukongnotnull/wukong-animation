# 章节静帧并发实施计划

目标是让多个章节在同一影片中独立抽帧自查。CLI 按独立抽帧选项跳过写入与工作台登记，复用 Node.js 引擎原有的 Browser 和 Remotion 渲染，再把产物留在各批次的临时目录。完整静帧、词级检查和副版沿用原流程。

1. 在 CLI 生命周期测试与渲染集成测试中覆盖锁被持有、两批并发、未请求镜头导入错误与全片时间轴。先运行新用例，确认原实现会阻塞或打包无关镜头。
2. 在 CLI 命令目录和媒体命令增加独立抽帧分支。在 `core/job.mjs` 复用静帧生成和接触表拼装，并隔离临时文件。使 Remotion 静帧只打包所需镜头，确保共享字体的下载临时文件互不覆盖。
3. 更新命令帮助和导演技能。运行相关生命周期、静帧、词级检查、工作台测试及仓库 lint，核对新产物与现有路径后提交。
