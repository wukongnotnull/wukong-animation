# 工作台两侧栏只由用户手动收起或展开

## 问题与目标

用户于 2026-11-13 提出：“文件栏和审阅栏不要随着浏览器的宽度进行自动隐藏，需要折叠还是展开，有用户手动操作”。

现状（FR-33 原窄窗设计）：`plugin/engine/workbench/app.css` 在窗口宽度不超过 1100px 时隐藏文件栏和审阅栏，只留中央预览，改用“文件 / 预览 / 意见 / 检查”四个按钮切换；同一断点还把“收起文件栏”“收起审阅栏”“调整栏宽”隐藏。用户缩窄浏览器后两侧栏自行消失，且无法用原来的按钮恢复。

本规格按项目约定默认通过，修订 FR-33 的窄窗部分。目标：两侧栏是否显示只取决于用户的手动操作，与窗口宽度无关。

## 范围与行为

1. 任何窗口宽度都保持“文件栏 / 预览 / 审阅栏”三栏。文件栏、审阅栏只在用户点击“收起文件栏”“收起审阅栏”后隐藏，点击“展开……”后恢复。
2. “收起/展开文件栏”“收起/展开审阅栏”“调整栏宽”在任何宽度都显示、可操作。收起状态与栏宽照旧记在本机会话的 `layout` 里，刷新、重新打开和改变窗口宽度都不改变它。
3. 移除“文件 / 预览 / 意见 / 检查”四个切换按钮及其面板状态（页面的 `data-panel`、脚本里的 `panel`）。审阅栏里“版本与检查”和“批注”始终同时显示。
4. 窗口放不下已展开的栏时，中央预览保留 320px 最小宽度，工作区横向滚动。页面不替用户收起任何一栏；要腾出空间由用户自己收起。
5. 与栏位无关的窄窗适配保留：顶栏与状态栏换行、字号与留白收紧、分镜表在 600px 以下展开为字段卡片。

## 非目标

不改收起状态的存储位置与栏宽范围（文件栏 180～340px，审阅栏 260～460px）；不改预览、批注、版本日志等其他功能；不升版本、不发布、不推送。旧会话里已保存的 `panel` 字段不再读取，也不清理。

## 验收标准与测试

- `tests/integration/workbench.test.mjs` 新增断言：页面不再含 `data-panel` 切换按钮，仍含两个收起按钮和栏宽控件；`app.css` 的任何 `@media` 规则都不对 `.workspace`、`.library`、`.inspector`、两个收起按钮和 `.layout-controls` 设置 `display` 或 `grid-template-columns`。运行 `node --test tests/integration/workbench.test.mjs`。
- 浏览器实测 1440、1024、768、480 四个宽度：两侧栏默认都在；收起其中一栏后改变宽度仍保持收起，展开后改变宽度仍保持展开；480 宽度下工作区可横向滚动到审阅栏。
- `npm run lint` 检查文档一致性。
