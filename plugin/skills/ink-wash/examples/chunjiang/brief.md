# 《春江花月夜》制作简报

## 一、目的与受众

- **用途**：wukong-animation 插件水墨风格的长篇旁白示范片；直接在插件仓库 `plugin/skills/ink-wash/examples/chunjiang/` 里制作（分支 `feat/ink-wash-chunjiang`）
- **投放平台**：插件仓库示范；也可单独发视频号 / B 站（推断）
- **目标受众**：喜欢古诗、国风的观众，以及想用本插件做片的创作者（推断）
- **看完后希望观众**：在一夜江月里静下来，感到"人生代代无穷已，江月年年望相似"的悠远，也带一点人间相思（推断）

## 二、内容

- **故事 / 主题**：张若虚《春江花月夜》，旁白读全诗，不删减
- **一句话核心信息**：江月年年相似，人生代代相续；从对宇宙的一问，落到人间的相思与月下的归思（推断）
- **基调关键词**：空明、悠远、淡淡的相思（推断）
- **必须出现的元素**：春江潮水连海平、海上明月共潮生、月照花林似霰、江天一色孤月轮、江畔的人、白云一片、扁舟、明月楼、捣衣砧、鸿雁与鱼龙、斜月沉入海雾，"落月摇情满江树"收尾（推断）
- **禁忌**：无
- **参考片 / 参考图**：无

## 三、制作规格

| 项 | 规格 |
|---|---|
| 片长 | 约 2 分钟，以配音实测为准（全诗 36 句 252 字，慢读、句间停顿 ≥ 0.8 秒）；超出水墨风格建议的 15–60 秒，按全诗做 |
| 画幅 | 16:9 横屏，1920×1080 |
| 人声 | 画外旁白，读《春江花月夜》全诗 |
| 配乐 | 有：稀疏古琴单音 + 潮水、流水铺底，不做连续旋律；说话时背景音乐随人声闪避 |
| 字幕方式 | 两者（`both`）：烧录一版 + 无字幕成片配 srt；中英双语（中文在上、英文在下），英文由导演逐句意译 |

## 四、交付

- **交付形式**：成片 + 剪映草稿；定版后开 PR 合入插件仓库（随 STYLE.md 示范片链接、冒烟测试基准图、CONTRIBUTING 时长例外说明一起提 PR）
- **期望交付时间**：无
