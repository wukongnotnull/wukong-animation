# v0.26.10 · 成片 SRT 与剪映字幕轨

- 有人声的正式成片自动附上同名 UTF-8 SRT。主版和副版各自生成，最终交付清单和审阅工作台提供文件入口。
- 剪映草稿用同一份台词定位生成 SRT 并自动导入一条可编辑的字幕轨。剪映专业版 11.8.0 已验证字幕时间、文字编辑、保存和重开。
- 新导出草稿的字幕默认在剪映面板显示 `X=0、Y=-788`。1080p 实测字幕完整显示，720p 的字幕需在剪映中上移才能进入画面。

## 升级

原生插件通过原安装渠道更新并重新加载。其他 Agent 可下载本次发布的 `wukong-animation-agent-skills-v0.26.10.zip` 和 `SHA256SUMS`，校验后按原安装参数升级。
