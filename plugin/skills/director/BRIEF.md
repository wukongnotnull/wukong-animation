# 制作简报 brief.md

第 2 道工序的交付物，审片节点 ① 制作简报签批。模板 `engine/templates/brief.md`，`wka brief <片名>` 建出空白稿 `films/<片名>/brief.md`。导演按追问结果填写，签批后第 3 道起各工序以它为制作规格的依据。怎么追问见 `SKILL.md` 第 2 道。

- 用户在话里已经说清的项直接采用；故事 / 主题取自用户的话。
- 从用户原话推断、用户在追问中确认过的项，末尾标「（推断）」。
- 以用户的选择为准。选的人声故事里还没有（比如选了对白，故事里却没有说话的角色），简报里写一句「故事里还没有台词，第 4 道写文学脚本时会补出说话的角色和人声文案」，第 4 道照此补写。

**各项写法与推荐答案**（推荐答案即默认规格，追问时作为推荐答案给出）：

| 部分 | 项 | 推荐答案 / 说明 |
|---|---|---|
| 一、目的与受众 | 用途 | 必填；按故事推断后请用户确认 |
| | 投放平台 | 必填；决定画幅推荐 |
| | 目标受众 | 必填 |
| | 看完后希望观众 | 必填；写观众看完的感受或行动 |
| 二、内容 | 故事 / 主题 | 必填；取自用户的话 |
| | 一句话核心信息 | 必填 |
| | 基调关键词 | 必填；2–3 个 |
| | 必须出现的元素 | 品牌名、logo、slogan、CTA 等；与禁忌、参考同一轮问一次，没有写「无」 |
| | 禁忌 | 有就写，没有写「无」 |
| | 参考片 / 参考图 | 有就写，没有写「无」 |
| 三、制作规格 | 片长 | 15–30 秒 |
| | 画幅 | 16:9 横屏；投放竖屏平台时推荐 9:16 |
| | 人声 | 无人声；故事本身有台词、旁白时推荐对应的人声 |
| | 配乐 | 有配乐 |
| | 字幕方式 | 只在有人声时问，同时问要不要中英双语。外挂 srt、只中文（风格另有推荐的从风格，如 keynote 推荐双语）；无人声直接记「不出」。取值见下表 |
| 四、交付 | 交付形式 | 只交成片；用户还想在剪映里接着剪时推荐「成片 + 剪映草稿」。见下表 |
| | 期望交付时间 | 有就写，没有写「无」 |

**字幕方式**：第 3 道 `wka init` 之后写进 `film.json` 的 `subtitles.mode`，要中英双语再加 `"bilingual": true`，第 11 道按它执行。

| 字幕方式 | `mode` | 适合 |
|---|---|---|
| 不出字幕 | `none`（或不写 `subtitles`） | 无人声的片子（默认），或用户明确不要 |
| 外挂 srt | `srt` | 有人声的片子（默认）：成片画面干净，播放器或平台按需显示 |
| 烧录进画面 | `burn` | 要发到不支持外挂字幕的平台 |
| 两者都要 | `both` | 既要烧录版，也要单独的字幕文件 |

**交付形式**：

| 交付形式 | 适合 | 第 14 道 |
|---|---|---|
| 只交成片 mp4（默认） | 片子拿去就能用 | 请用户确认不需要剪映草稿，签批 ⑪ 后结束 |
| 成片 + 剪映草稿 | 用户还想在剪映里加字幕、调音量、接到别的片子里 | 导出剪映草稿交付 |

示例：`ink-wash/examples/chunjiang/brief.md`。
