## 1. 问题与目标

现有录音接口偏向逐句音频，按文件时长生成同步点；缺人声时还有 TTS 和估算回退。目标是完整接收一段或多段用户录音，本机定位句段，有稿优先对应原稿，无稿识别，再用于画面编排。不得擅自改变录音、把估算当准确定位，或输出字幕。

## 2. 架构与组件边界

- 保留 `audio.voices[]` 作为每段录音的输入：文件、编排起点、可选已知台词与 cue。一个文件可以包含多句，混音仍只使用一次完整录音；句段定位另存，不通过复制音频条目重复混入整段。
- 新本地语音模块负责预检、读取/准备本地识别组件、运行识别、将识别证据匹配到原稿、记录待核实项、导入人工时间点与检查来源是否过期。
- 新 `align-voice` 命令提供准备、识别/对齐、人工时间点导入和状态报告入口；工作台只查看定位结果与标记问题，修正在对话中执行，不新增编辑器或独立签批门。
- 声轨制作消费当前有效的录音和时间点；生成动画/整片小样之前检查必要录音、时间范围和冲突，不自动裁切或修改已批时长。

## 3. 接口、数据与行为

### 输入和缺失处理

新流程 `voice_source` 仅为 `user` 或 `none`，未明确来源但有录音时按用户录音处理；AI 模式明确拒绝。`user` 模式缺录音、文件损坏或没有可用时长时返回需要素材，禁止估算声音与 TTS。`none` 正常制作无声或仅配乐/音效影片。

每段保留原文件和自然语速；多段按明确的起点/台词次序编排，不能可靠确定顺序时先在对话核实。识别、定位、混音不覆盖输入文件。录音超出已批片长，或识别内容与原稿存在实质差异时，生成具体待确认事项，不能静默截断或重写剧本。

### 本地识别与对齐

首选独立本地 whisper.cpp CLI 适配器，支持 CPU，使用本地模型文件，不调用云服务。组件可从既有 PATH/显式本地位置发现；缺失时显示对应系统准备步骤与官方模型来源，提供可执行的准备入口。组件与模型下载是联网准备，识别本身不上传录音。首次准备结果、失败原因和本地文件位置可检查。

从实际识别的文字及时间戳产生句段证据；已有原稿通过保序文本匹配与识别结果对应，不把原稿提示词当强制对齐。记录真实方法、输入摘要、模型/组件信息、匹配和未匹配片段。缺失、非法时间、重复/歧义匹配、文字不符和无法可靠定位的结果标待确认，不伪造准确句段。

默认句段时间点；逐字同步只有明确要求时启用，实验性词级时间戳不得冒充经过人工确认的精确点。识别输出使用内部 JSON/可读报告，不生成 SRT/VTT，不接字幕接口。

### 定位记录与人工补充

记录保留每段音频的文件摘要、编排起点、原稿摘要、句段文本、源音频内起止时间、全片时间、来源方法和复核状态。记录存于项目自己的 `.wka/`，可读结果放入 review，登记为制作小样的过程产物。

人工导入采用 JSON 句段时间点，要求关联当前源文件/原稿摘要，时间必须有限、递增且落在对应录音范围内。用户明确确认后记录为人工依据，不通过默认选中或自动重跑确认。文件、原稿或编排起点改变时旧定位过期；无关录音结果可复用。定位 cue 保留稳定名称，清理本模块拥有的旧点，不删除用户无关手工 cue。

### 混音与小样

先测量真实人声并更新有效同步点，再运行依赖同步点的配乐脚本和混音。音轨超出全片时长明确报冲突。制作小样使用当前录音/混音版本，缺失必要素材与未处理阻塞不能签批完整小样。全部录音关闭后不沿用旧混音。局部小样不能作为整片声音已审的依据。

## 4. 约束、兼容性与非目标

- 首版仅本地处理，不接在线识别，不上传录音、原稿或时间点。
- 不自动删词、截断、变速，不生成 AI 人声或字幕。
- 不增加独立识别签批节点；不把独立显卡设为统一前提。
- 不承诺所有机型自动处理；不可用时允许人工补时间点完成制作。
- 模型、依赖及平台准备方案不改变发布版本号；视频生成批次仍单独确认。

## 5. 错误处理与运维

区分组件缺失、模型缺失/下载失败、不支持的平台、处理失败、无语音、台词不符、时间越界和来源过期。结果写入原子化，失败不覆盖已有有效定位或用户素材。命令通过参数数组运行本地程序，不使用 shell 拼接用户路径。中英文、中文/空格路径分别验证；长录音进度可见、进程结束状态真实，不以超时当成功。

## 6. 验收标准与测试

先以真实输入数据写失败测试：整段/多段唯一混入、真实时长边界、无人声/缺录音、台词匹配/歧义/不符、人工时间点越界/来源过期、改变某段只使相关 cue 失效、失败不改原文件、命令不产生字幕。

组件调用的契约测试可用受控本地可执行夹具验证参数与错误传递；不能据此宣称真实识别已通过。实际本地组件须另用已有录音验证有稿与无稿路径，报告所用组件、模型、系统、结果、待人工项和未覆盖平台；没有真实语音证据时明确保留该验收缺口。涉及小样/成片生成的整链测试在获得该批开始授权后执行。
