# v0.26.0 · 文档搜索与剧本模板优化

> 插件版本 v0.26.0；制作流程版本 v1.24.0；工程协议 FLOW 8。

工作台现在支持在当前文档中搜索和定位内容。剧本与简报模板同步精简，明确素材处理权限、完整人声稿和屏幕文字的分工，分镜规范统一动效与副画幅术语。

## 工作台文档搜索

- 搜索当前文档，支持中文和忽略大小写的字面量匹配、匹配高亮与计数，以及上下循环跳转。
- 使用 Enter、Shift+Enter 和 Escape 操作搜索；切换文件清空搜索，同文件版本和原文视图变化后重新匹配。
- 搜索保持文档文字节点和批注坐标不变；浏览器不支持 CSS Custom Highlight 时，降级为当前匹配元素描边与定位。
- 适配浅色、深色与窄栏布局，无新增运行依赖。

## 剧本、简报与分镜

- 剧本采用 P01 等自由段落编号，连接正文、段落结构、人声和屏幕文字，适用于剧情、科普、观点与意象作品。
- 口播讲解以完整人声稿为主体，正文保留段落摘要与表达目标，避免重复维护整篇讲解。
- 区分素材合集、待修改口播稿与已确认定稿，记录来源、已有改稿权限和锁定内容。
- 增加录音前朗读检查、表达依据与屏幕文字的信息分工；区分目标片长、预计时间与录音实长。
- 参考片与参考图并入必填素材清单，精简简报中的镜头规模、单镜上限、人声素材状态与交付时间字段。
- 分镜栏目统一为「运镜 / 动效」，画幅附表统一为「副画幅重排」；结构检查兼容历史附表名称。

## 稳定性

- 修复剧本空白模板中的文件链接导致便携包构建失败的问题。
- 文件哈希测试保留真实文件改写和 mtime 恢复，并明确控制 ctime 变化，避免依赖文件系统时间戳精度；运行时哈希算法未改变。

## 兼容性与升级

制作流程仍为九道工序、最多八个审片节点，工程协议仍为 FLOW 8。本次不增加工程迁移，也不自动改写已有影片文稿或签批记录。

原生插件通过原安装渠道更新并重新加载；关闭旧工作台后，用新版插件重新打开。其他 Agent 下载本次发布的 `wukong-animation-agent-skills-v0.26.0.zip` 与 `SHA256SUMS`，核对校验和后按原安装参数升级。

## 验证

剧本模板与分镜术语两个 PR 各自通过全部 14 项 CI，包含三平台安装契约、lint、smoke、剪映集合与合并门禁。工作台搜索已有 Chromium 交互、浅深主题、响应式、键盘与批注坐标验证；Firefox / Safari 尚无实测结果。

本次版本更新另通过 13 项桌面插件、便携安装与安装诊断测试，`npm run lint` 通过。发布资产提供完整便携包与 SHA-256 校验文件。
