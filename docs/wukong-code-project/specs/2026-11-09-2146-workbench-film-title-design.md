# 工作台显示影片标题

用户要求把「当前影片」中的「示范片」改为「AGI科普讲解」。列表目前使用目录名。已有审阅记录和链接依赖原目录对应的影片身份，因此改动影片配置和列表显示规则。

工作台从普通 `film.json` 读取非空字符串 `title` 作为列表名称。无标题、配置不可读或尚未建好配置时显示目录名。沿用项目文件范围检查和同名条目的路径区分规则。

`/api/films` 保留已有字段、目录和影片 ID。页面用已有轮询发现显示名称变化，继续选中同一影片。此片只修改 `film.json` 的标题字段。测试用可独立运行的临时片目录，不生成视频。

验收时验证标题变化出现在 `/api/films`，原 ID 仍能查询报告，缺失、空白和损坏配置能使用目录名。核实本地 63711 服务继续提供原片的审阅记录，浏览器列表显示新标题。
