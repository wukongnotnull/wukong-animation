# 水墨写意 · ink-wash

这是一个**风格** skill：只规定"画成什么样、用什么技术画"。
**拍片流程请按 `director` skill 执行**（本目录上一级的 `director/SKILL.md`）。

## 开工前必读

1. `STYLE.md` —— 美学规范、禁忌清单、交付前质检。是硬约束。
2. `TECH.md` —— 技术选型与积木 API（`wk.ink.*`、`wk.c2d.*`、`wk.gl.*`）。

## 技术声明（style.json）

- 管线：`browser`（无头 Chromium 逐帧渲染）
- 工具包：`canvas2d`（笔触、纸、晕染面、雾、题字、印章）+ `webgl`（墨滴晕开 shader）
- 风格积木：`scripts/ink.js` → `wk.ink`
- 字体：马善政楷书 / 志莽行书（按需下载；不可用时退回思源宋体）
- QA 阈值：留白 ≥ 40%，朱砂 ≤ 3%，相邻帧差 ≤ 18，硬切 ≤ 2

## 常见问题

- **雾带太厚会盖住舟和山脚的皴笔**：雾 alpha ≤ 0.85，且不要压在主体上。
- **山被"切断"**：山层的 `x1` 处必须收到地面，`wk.ink.mountain` 默认右端 14% 收尾（`taper`）。
- **墨滴残影**：墨滴化山后要几乎淡尽（dropFade 到 ≥ 0.95），只留一点"山魂"。
- **渲染慢**：画完不再变化的东西（山层、写完的舟、写完的题字）一定要缓存；`wk.ink.boat`、`verticalText` 写完后会自动缓存。
