# 简报填写规范（brief.md）

> 简报是这支片的制作规格：签批后，第 3 道起各工序都以它为依据。

- **工序**：第 2 道 · 审片节点 ① 制作简报
- **模板**：`engine/templates/brief.md`，由 `wka brief <片名>` 建出空白稿 `films/<片名>/brief.md`
- **流程**：怎么追问、怎么提交见 `../SKILL.md` 第 2 道
- **示例**：`ink-wash/examples/chunjiang/brief.md`

## 一、通用规则

- 用户在话里已经说清的项直接采用；故事 / 主题取自用户的话。
- 从用户原话推断、用户在追问中确认过的项，末尾标「（推断）」。
- 用户带来了现成的口播稿（旁白、讲解稿）：`wka brief` 建好片目录后，把原文存为 `films/<片名>/口播稿.md`，之后不改这个文件（改稿在剧本里改，见 `STORY.md`「三、有口播稿时」）。故事 / 主题、片长、人声按下表「有口播稿时」的写法填。
- 以用户的选择为准。选的人声故事里还没有（比如选了对白，故事里却没有说话的角色），简报里写一句「故事里还没有台词，第 4 道写剧本时会补出说话的角色和人声文案」，第 4 道照此补写。

## 二、各项写法与推荐答案

推荐答案即默认规格，追问时作为推荐答案给出。选填项用户说没有就写「无」。

| | 目标受众 | ✓ | |
| | 看完后希望观众 | ✓ | 观众看完的感受或行动 |

| | 一句话核心信息 | ✓ | |
| | 基调关键词 | ✓ | 2–3 个 |
| | 必须出现的元素 | | 品牌名、logo、slogan、CTA 等；与禁忌、参考同一轮问一次 |
| | 禁忌 | | |
| | 参考片 / 参考图 | | |
| 三、制作规格 | 片长 | ✓ | 15–30 秒；有口播稿时按字数估（中文约每秒 3.6 字），写「约 N 秒（按口播稿 M 字估）」 |

## 三、字幕方式取值

第 3 道 `wka init` 之后写进 `film.json` 的 `subtitles.mode`，要中英双语再加 `"bilingual": true`；第 11 道按它执行。

| 字幕方式 | `mode` | 适合 |
|---|---|---|
| 不出字幕 | `none`（或不写 `subtitles`） | 无人声的片子（默认），或用户明确不要 |
| 外挂 srt | `srt` | 有人声的片子（默认）：成片画面干净，播放器或平台按需显示 |
| 烧录进画面 | `burn` | 要发到不支持外挂字幕的平台 |
| 两者都要 | `both` | 既要烧录版，也要单独的字幕文件 |

## 四、交付形式取值

| 交付形式 | 适合 | 第 15 道 |
|---|---|---|
| 只交成片 mp4（默认） | 片子拿去就能用 | 请用户确认不需要剪映草稿，签批 ⑫ 后结束 |
| 成片 + 剪映草稿 | 用户还想在剪映里加字幕、调音量、接到别的片子里 | 导出剪映草稿交付 |
