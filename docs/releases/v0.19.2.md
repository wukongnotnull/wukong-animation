# v0.19.2 · 制作可靠性修复

本版发布第一批三项可靠性修复，减少制作失败、错误复用和初始化时误提交文件的问题。[修复 PR #114](https://github.com/wukongnotnull/wukong-animation/pull/114) · [跟踪 #113](https://github.com/wukongnotnull/wukong-animation/issues/113)

## 改了什么

- **提前发现重复镜头编号**：在准备渲染资源之前拒绝重复的镜头 ID，并提示冲突编号，避免镜头结果相互覆盖或错误复用。
- **损坏缓存可恢复**：镜头缓存清单损坏时提示并重新生成缓存，不删除源文件、音频或签批记录；清单通过临时文件和原子替换写入，写入失败保留旧清单和旧缓存。文件读取权限等 I/O 错误仍明确报错。
- **首次提交保护已有改动**：新项目的首次自动提交只包含 `.gitignore`，用户原有的暂存和未暂存改动保留在原处。

## 升级

通用、Codex、Claude 插件清单及 Claude marketplace 统一为 **0.19.2**。导演流程仍为 1.17.1，引擎包及依赖版本仍为 0.2.0；修复后的引擎源码随插件一同分发。

Codex 原生 Git 来源通过指定 marketplace 更新，再重新安装已配置的同名插件：

```bash
codex plugin marketplace upgrade wukong-animation
codex plugin add wukong-animation@wukong-animation
codex plugin list --marketplace wukong-animation --json
```

核对安装版本为 0.19.2，打开新聊天加载新版本。Claude Code 按原 marketplace 更新；其他 Agent 下载本版 `wukong-animation-agent-skills-v0.19.2.zip` 和 `SHA256SUMS`，核对校验和后，使用相同 agent、scope、project、variant 执行 `upgrade`。各宿主更新机制不同，发布不会自动替换所有用户的本地安装。
