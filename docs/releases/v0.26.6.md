# v0.26.6 · 工作台文档内媒体与链接

- 工作台中的分镜稿等 Markdown 文档可直接显示已登记的图片，包括表格单元格里的图片。
- 视频和音频播放器随文档显示，点播放时加载。收起播放器会暂停播放。
- 已登记的本地文档链接在工作台内打开，HTTP 和 HTTPS 网页链接在新标签页打开。可切换至原文查看完整 Markdown。

## 升级

原生插件通过原安装渠道更新并重新加载。其他 Agent 可下载本次发布的 `wukong-animation-agent-skills-v0.26.6.zip` 和 `SHA256SUMS`，校验后按原安装参数升级。
