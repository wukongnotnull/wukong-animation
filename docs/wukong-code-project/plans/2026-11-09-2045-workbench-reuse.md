# 自动复用工作台实施计划

目标：打开新项目自动接入已运行的同端口工作台，浏览器自动更新选择器。

架构：CLI 协调本机登记、锁与实例握手；HTTP 服务持有动态目录清单并保护 CLI 控制入口；浏览器沿用轮询更新列表。技术栈为 Node.js HTTP/文件系统和现有原生浏览器界面。

全局约束：不引入登录或浏览器鉴权长链接，不全盘发现项目，不启动视频生成，不自动签批，不升版、改安装缓存或自动发布。记录类 CLI 操作保持单片且不启动/连接服务。

1. 新建 tests/integration/workbench-reuse.test.mjs，覆盖复用、幂等、重启、并发、身份与来源边界。先运行确认功能缺失失败。
2. 新建 cli/workbench-service.mjs，负责登记与连接；修改 workbench-server.mjs 增加动态接入、受保护控制路由与独立会话存储；修改 commands/workbench.mjs 区分首次持有服务与复用后退出。运行新增测试到通过。
3. 修改 workbench/app.js，轮询更新列表且保留现有 UI；启动时读取 film 查询参数。用真实浏览器验证接入前后页面未重载、选择保持及新项目可切换，测试项目不生成视频。
4. 更新帮助、WORKBENCH 文档和导演入口；跑工作台、CLI、桌面插件相关无视频测试及 lint。升级当前服务一次，保留用户页面与历史文件，提交并完成收尾。
