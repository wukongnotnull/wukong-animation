# Keynote 横屏主图区重心

横屏使用 1920×1080 的设计坐标。L02 和 L03 的图位中心是 y=556，L06 两侧图位中心是 y=592，均低于画布中心 y=540。截图中的左右并列内容则由影片的自定义 SVG 分层和镜头取景控制。隐藏原图的标题分层后，镜头仍对准画板中心，剩余前景偏下。

- L02、L03 和 L06 的主图区中心对齐 y=540。沿用各自图位尺寸，收紧标题与下方内容之间的间距。L06 的列标签和注释跟随图位上移，维持原有间距和两列对齐。
- Keynote 构图规范补充分层素材的取景方法。选定实际显示的图层后，按可见内容的外接矩形取景，连线和高亮跟随素材，并在字幕显示时检查其下沿与双语字幕之间的距离。
- 几何调整范围为横屏 L02、L03 和 L06。既有影片在校样副本中验证取景。

验收通过版式单元测试核对主图中心、图位尺寸、版块间距及现有安全区。渲染横屏修改前后静帧，并用截图对应镜头的可见前景验证自定义取景。
