# v0.24.0 · 影片目录布局 v7

本版重整每部影片的目录结构，让成片、审阅文件、状态记录和输入素材各归其位，便于管理大片和多画幅版本。8 道工序和 7 个审片节点不变，工程 flow 由 6 升至 7。

## 不兼容变更

- 新布局是唯一布局，不兼容旧片。flow 6 及更早的影片升级后只读留档，续作请新建项目并复用素材。
- 升级后，`wka init-project` 会更新项目 `.gitignore` 里的 wukong-animation 段落；旧规则会挡住 `review/` 里的待审文件。

## 新布局

- **根目录**只留 `film.json`、`brief.md`、`story.md`、`storyboard.md`、`sync-points.json`。
- **成片**放 `成片/<片名>-<画幅>.<扩展名>`；`film.json` 的 `export.name` 可改前缀。所有画幅的输出（含主版）都带画幅后缀，如 `-16x9`；镜头源文件不带后缀，副版覆盖文件为 `s01.9x16.tsx`。
- **缓存**：`.cache/<后缀>/` 只放可删除物。
- **状态与证据**进 `.wka/`：`operations.json`、`main-check.json`、`voice-sources.json`、`approved/`、`review-notes.json`、`materials-origin.json`。其中含进程号和本机中间状态的几项不进版本库。
- **审阅文件**分到 `review/` 的 `小样/ 静帧/ QC/ 声轨/ 素材/ 交付/ 台词/` 子目录，原 `stills/` 并入 `review/静帧/`。文字报告纳入版本管理，大媒体不进。
- **输入素材**统一放 `media/`（图片、视频）、`audio/voice/`（录音）、`资料/`（文字资料）。

## 新增

- `wka materials <片目录> --add <文件或目录>`：按类型导入素材，内容相同的跳过，重名加序号，来源记入 `.wka/materials-origin.json`；单个文件超过 20MB 且未配置 Git LFS 时提醒。清单写到 `review/素材/素材清单.md`。
- `wka status`：列出每部影片各目录的占用。
- `wka clean <片目录> --deep [--yes]`：先列可再生内容的清单，加 `--yes` 才删；成片、素材、源文件、签批与交付记录引用的文件一律保留。

## 修复

- `wka materials` 不带 `--frames` 时，抽帧数默认变成 0，现恢复为 3。

## 升级方式与版本

三种原生插件清单和 marketplace 从 0.23.1 升至 0.24.0；导演流程文档从 1.22.0 升至 1.23.0；工程 flow 6→7。引擎包保持 0.2.0。

升级前请先在旧版插件下收尾仍在制作的影片：升级后这些影片只读。原生插件通过原安装渠道更新并重新加载；其他 Agent 使用正式发布时附带的 `wukong-animation-agent-skills-v0.24.0.zip` 和 `SHA256SUMS`，校验后按原安装参数升级。

## 验证

发布前 `npm test`（623 项）、`npm run lint`、`npm run smoke`、`npm run test:jianying`（27 项）全部通过；标签上的检查结果在正式发布时写入 GitHub Release。
