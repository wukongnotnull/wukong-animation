# 剧本稿人声分行

剧本的「人声文案」按语意和自然换气分行。短句可以独占一行，长句在自然停顿处拆分。完整词组、专名和带单位的数字放在同一行，保留台词原文、标点和顺序。

继续使用带段落编号和说话人的编号条目。多行台词使用 Markdown 列表内的硬换行，每行缩进与条目正文对齐。源文件逐行可读，工作台排版阅读把各行显示在同一条目内，并保留台词的原文坐标。短台词可以与说话人同一行，已有的单行写法和「无」继续可读。

分镜逐镜表继续在同一「人声」单元格内连续书写台词。把剧本台词放进分镜表时，去掉录音稿的换行标记，保留文字和标点。

用包含多处停顿、说话人切换和单行台词的剧本验证显示，检查桌面和窄屏排版、搜索、原文模式和跨行批注定位。同时核对分镜表的连续台词和镜头定位。
