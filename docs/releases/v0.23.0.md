# v0.23.0 · 逐词时间表与工作台文件管理

本版包含 [逐词时间表 #144](https://github.com/wukongnotnull/wukong-animation/pull/144)、[第 7 道签批绑定高清成片 #146](https://github.com/wukongnotnull/wukong-animation/pull/146)、[静帧增量检查 #147](https://github.com/wukongnotnull/wukong-animation/pull/147) 和一组审阅工作台改进。8 道工序、7 个审片节点和工程 flow 6 不变。

## 台词定位与词级检查

`wka align-voice` 默认同时生成逐词时间表 `review/逐词时间表.md`。镜头可以用 `word:<录音cue>:<序号>` 作为 cue，让画面和音效踩在具体的词上；未就绪的词在渲染时报错，不会改用估算时间。

`wka still --at` 默认不再做词级检查，需要时加 `--word-review`，只检查涉及的镜头并另存局部报告。检查帧和人声片段改存 `.cache/<画幅>/word-review/`，按镜头渲染哈希增量复用。被中断时会释放写入锁，工作台忽略所有者已退出的残留锁。

## 调整画幅

横屏小样通过后，先确认是否生成高清成片。签批只用于审片节点，工序内部的分步确认不再调用 `wka signoff`。全部副版的高清成片和 QC 就绪后才签批第 7 道，签批绑定高清成片，不再绑定小样。

## 审阅工作台

- 文件栏新增搜索框和按类型分类的标签页（文档、图片、音频、视频、工程、其他），交付物很多时可以快速定位。
- 版本与检查区新增版本日志，逐版显示更新内容。
- 已发送的批注转入批注区下方列表，只读显示待办与已完成。发送批注后放进对话输入框，等你确认再发出。
- 制作写入工程期间仍可查看上次登记的版本。点击镜头后，高亮留在被点击的镜头上。
- 页面顶部显示当前插件版本号。

## 升级方式与版本

三种原生插件清单和 marketplace 从 0.22.0 升至 0.23.0；导演流程文档从 1.20.0 升至 1.21.0。引擎包保持 0.2.0。

原生插件通过原安装渠道更新并重新加载；其他 Agent 使用正式发布时附带的 `wukong-animation-agent-skills-v0.23.0.zip` 和 `SHA256SUMS`，校验后按原安装参数升级。发布不会自动替换每位用户的本地副本。
