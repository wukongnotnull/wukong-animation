# v0.16.0 · 主流 Agent 完整技能包

本版在 v0.15.0 的制作流程上，增加可独立安装的完整技能包。v0.15.0 保持原样，不包含这些安装改动。

## 新增与改进

- **完整技能包**：一次安装带上引擎、风格、模板和制作指令，不依赖仓库里的相邻目录。发布文件为 `wukong-animation-agent-skills-v0.16.0.zip` 与 `SHA256SUMS`。[#98](https://github.com/wukongnotnull/wukong-animation/issues/98)、[#99](https://github.com/wukongnotnull/wukong-animation/pull/99)
- **安装生命周期**：`install`、`status`、`upgrade`、`uninstall` 支持项目级和用户级。重复安装零变更；用户改过的文件、未知同名目录和损坏的包会停下来，不静默覆盖。
- **25 个工具族**有隔离目录下的安装契约，包括 Cursor、Copilot、Gemini CLI、OpenCode、Windsurf 等。Cline 仍是候选，安装器拒绝写入。ChatGPT 桌面继续使用原来的插件安装。
- **通用宿主交付**：没有文件链接或预览时，列出真实路径、文件类型和未验证说明。Codex 与 Claude 的原有链接格式不变。
- **macOS 路径**：发布包在 `/var` 与 `/private/var` 指向同一文件时会实际执行安装。

## 升级说明

- 插件各宿主清单统一为 **0.16.0**；制作流程 **v1.14.0**。引擎及 npm 依赖仍为 0.2.0，已有依赖可继续使用；新环境仍需执行 setup。
- Claude Code、Codex、ChatGPT 桌面沿用 README 里的原生命令升级。其他工具下载本版压缩包，解压后用同一 agent、scope、project 执行 `upgrade`。安装器不会自动下载最新版，也不会降级。
- 15 道工序与 12 个审片节点不变。已有作品、手改字幕和已签批快照不因这次发版重写。

## 验证与边界

发布前执行 lint、安装契约、全量测试、示范片冒烟，以及从解压后的发布包安装。结果记在发布 PR。

实际在宿主里发现入口并完成最小渲染的，目前只有 Codex CLI。其余工具只验证了安装目录契约。媒体打开仍未验证，不能把文件存在当成播放成功。#98 继续记录这些边界，#93 的人工播放待办保持独立。
