# v0.17.1 · 剪映草稿交付修复

本版修复草稿交付的切点重叠、英文误拦截和字幕字号问题，并包含 v0.17.0 之后已合并的 FFmpeg 8 时长兼容与渲染提速改动。

## 改了什么

- **切点连续**：由统一帧切点生成微秒起止，长度取终点减起点，避免多镜头草稿因1μs重叠导出失败。真实重叠、缺口和不足素材继续拒绝，不静默裁短目标区间。[PR #105](https://github.com/wukongnotnull/wukong-animation/pull/105)
- **英文检查准确**：超长和句号只提示警告，缺英文、中文错配及无效结构仍阻断；保留原文与术语。
- **字幕按实际版式导出**：纯草稿在原生尺寸重新测量，每条中英文分别写入实际字号与位置，长英文缩小后仍保持正确间距。字号换算考虑画布尺寸；导出后仍须在剪映实际复查替代字体与可读性。
- **FFmpeg 8 兼容**：视频轨容器时长允许至多1ms误差，避免末帧B帧样本的微小时长差导致有效片段反复重渲；帧数、逐帧时间戳和切点检查继续严格执行，并补齐真实媒体回归。[PR #103](https://github.com/wukongnotnull/wukong-animation/pull/103)、[PR #104](https://github.com/wukongnotnull/wukong-animation/pull/104)
- **编码提速**：Browser高清片段和字幕烧录使用 `fast` 预设，CRF保持不变。不承诺所有场景具有相同提速比例或文件大小。

## 升级说明

- 通用、Codex、Claude插件清单与marketplace版本统一为 **0.17.1**。制作流程仍为v1.15.0，引擎及npm依赖仍为0.2.0，已有共享依赖可继续使用。
- Codex原生Git来源先刷新指定marketplace，再通过宿主支持的安装/刷新流程获取新清单；新聊天中核对实际加载版本，不直接修改缓存。
- Claude Code按原marketplace进行更新；其他Agent下载本版的 `wukong-animation-agent-skills-v0.17.1.zip` 和同次发布的 `SHA256SUMS`，核对后使用相同agent、scope、project执行 `upgrade`。不承诺所有宿主会自动更新。
- 不改用户作品、已签批成片或已编辑草稿。新导出继续保留回执复用、同名避让和用户编辑保护；需要另导时保留旧稿。
