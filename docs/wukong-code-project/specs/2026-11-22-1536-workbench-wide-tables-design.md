# 工作台文件预览宽度

## 问题与目标

分镜稿的十列表格曾被文档宽度上限和表格最小宽度同时约束，导致「人声」「音效」等列超出可见范围。其他交付物也应使用右侧预览区提供的空间。

## 布局

- 排版文档、原文、音频控件及附件或工程的文件列表铺满预览区，仅保留内外边距。
- 桌面宽表按可用空间分配列宽，长链接和文字在单元格内换行。分镜表给镜号、景别等短字段较窄的列，给画面和运镜较宽的列，人声、音效等字段各自有独立空间。表格在可用宽度不足时仍可在内部滚动。
- 图片和视频按原比例适配预览区可用宽高，完整显示。图片批注沿用实际画面内的相对坐标。移动端沿用逐行显示表格字段的样式。

## 验收

在 Chromium 的 1414px 窗口检查十列分镜，审阅栏开合时都能看到最后一列。在 390px 窗口检查所有字段。检查普通剧本、原文、音频和文件列表的宽度，横图和竖图的等比例缩放、图片批注的位置及视频画面完整性。
