# 工作台预览内容搜索

## 需求与界面

在预览工具栏的标题与版本操作之间放置搜索框，沿用工作台纸色／深色配色、字体与焦点样式。搜索范围只包含当前文档的可见文字，与左栏交付物名称搜索相互独立。宽栏居中展示；窄栏换行，不挤压现有操作。

支持中文、忽略大小写的字面量搜索、匹配计数、上一处／下一处循环跳转、Enter／Shift+Enter 跳转与 Escape 清空。空搜索不高亮；无结果显示明确提示。非文档、加载中、读取失败时隐藏搜索。

## 实现与边界

新增独立 search.mjs，使用原生 Range 与 CSS Custom Highlight API，保留 document.mjs 的 data-source 文字节点与批注偏移。以段落、表格单元格为搜索边界，允许跨加粗／代码行内节点匹配；原文按原始文字搜索。旧浏览器降级为当前匹配所在元素描边，不修改 DOM 文字或占用用户 Selection。

app.js 在载入当前文档后绑定搜索根节点。切换同文件的阅读模式或版本保留关键词并重新匹配；切换影片或文件清空。文档加载开始即清除旧高亮和计数，异步响应沿用现有渲染序号校验。仅扩展现有静态资源白名单，不新增 API、依赖或持久化数据。

## 验证计划

- 先测字面量匹配、Unicode 偏移、空输入与循环导航，再实现。
- 浏览器验证跨行内节点、表格、原文、切文件、切版本、空结果、键盘与批注偏移不变。
- 检查两种主题及 320／375／768／1024／1440／1920 宽度；保留工作台原有手动侧栏规则。
- 执行相关工作台单元／集成测试、架构检查与独立代码审查。
