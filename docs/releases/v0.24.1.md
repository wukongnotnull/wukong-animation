# v0.24.1 · 工作台手动折叠与审阅改进

文件栏和审阅栏现在只由用户手动收起或展开。缩窄浏览器不再自动隐藏两侧栏，收起按钮与调整栏宽始终可用；窗口放不下时工作区横向滚动。收起状态继续保存在本机，改变窗口宽度、刷新后都保留。

## 审阅改进

- 移除窄窗的“文件 / 预览 / 意见 / 检查”切换模式，任何宽度都沿用三栏布局，审阅栏里的版本检查与批注同时可见。
- 版本日志除增删行数外，还显示文字版本具体新增、删除的内容摘要，便于核对修改。
- 非 Codex 环境发送批注后，将待办文字复制到剪贴板，供用户粘贴回对话；不再打开不适用的 `codex://` 链接。
- 第 2 道方案简报签批前，导演先保存交审版本、自动打开审阅工作台，并在交付物清单首行给出地址。工作台负责预览与批注，签批仍由用户在对话里确认。

## 升级

原生插件通过原安装渠道更新并重新加载；已打开的旧工作台需关闭后，用新版插件重新打开。其他 Agent 下载本次发布的 `wukong-animation-agent-skills-v0.24.1.zip` 与 `SHA256SUMS`，校验后按原安装参数升级。

插件清单与 Claude marketplace 同步升至 0.24.1；引擎包保持 0.2.0，影片工程 flow 保持 7，与 v0.24.0 的影片兼容。

## 验证

发布前工作台、导演签批入口、桌面插件及便携安装相关测试 85 项全部通过（0 失败、0 跳过），`npm run lint` 通过。便携发布包按发布提交构建并核对 SHA-256。栏位改动已在 Chromium 的 1440、1024、768、480 宽度验证，并验证收起状态在改变窗口宽度及刷新后保持；Firefox 与 Safari 未验证。
