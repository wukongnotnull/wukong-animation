# 自动复用工作台验收

日期：2026-11-09；关联 [#127](https://github.com/wukongnotnull/wukong-animation/issues/127)。规格与计划提交 3f43b6f。

## 实现

CLI 优先握手已有工作台并接入明确目录；已有服务保持进程与端口，接入命令返回目标影片链接后退出。首次默认 63711，项目目录清单与端口持久保存；异常退出与死进程启动锁可恢复。--port 0 仍为隔离临时服务。运行记录与控制凭据使用受限本机权限，不进入浏览器、URL 或日志；控制接口拒绝浏览器来源。

页面轮询仅更新选择器，不重新载入当前交付物；目标链接可用 film 查询参数选片。统一私人会话保存在引擎用户数据目录，避免首片是历史档案时阻止新片保存草稿。旧私人草稿不读取或迁移，正式记录仍分片保存。

接入前校验整批目录及影片发现范围，持久保存后才发布列表。已有目录暂时不可用不阻止其他项目恢复，保留原清单和影片身份；损坏或新版登记不会自动覆盖。未知端口或不匹配实例不会收到项目接入请求，也不会被终止。
