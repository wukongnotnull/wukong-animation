# 工作台区分保存快照和文件修订号

工作台按保存次数给交付物快照编号，空白模板也会保存。剧本和分镜可以在正文中标注作者维护的修订号。同一份剧本会同时出现在「当前版本 v3」和「剧本版本 v2」两处，现有标签容易让人误以为它们是同一个编号。

页面凡显示工作台保存编号的地方使用「快照 N」，包括预览状态、交付物列表、历史选择和批注定位。检查区用一句话说明快照按保存顺序编号。正文原样展示。

只调整标签。快照编号、ID、时间、文件字节、检查和签批的绑定及返修记录均沿用当前数据。

用现有影片复现和验收。浏览器应显示「当前快照 3」，剧本原文仍显示修订 v2。切换历史快照应保留原绑定，已有返修继续指向同一个当前快照。
