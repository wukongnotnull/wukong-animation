# v0.22.0 · 签批入库与审阅工作台

本版包含 [工作台直接打开 #136](https://github.com/wukongnotnull/wukong-animation/pull/136) 和 [签批入库与审阅页 #138](https://github.com/wukongnotnull/wukong-animation/pull/138)。8 道工序、7 个审片节点和工程 flow 6 不变。

## 签批

审片通过前，本阶段点名的审阅文件必须已经提交，并记录生成文件的校验。未提交时不能把该阶段标为通过。

签批卡片询问「进入下一工序吗？」，选项为「进入」和「要返修」。最后一道有效工序询问「完成制作吗？」。

## 审阅工作台

工作台用来查看交付物和写批注。阶段通过、退回和复验仍在对话中完成。已发送的批注不留在页面上。制片写入新版本后，已打开的页面自行载入，未提交草稿留在原版本。

同一本机服务可以接入多部影片。打开新项目时复用已有服务并加入列表，直接输入本机地址即可使用。时间按镜头时钟 `01:23.45` 书写。

## 剧本、分镜与小样

方案简报、剧本和分镜稿不写版本号。剧本写故事、台词和画面上有哪些字；景别、运镜、声音和文字出现形式写在分镜稿里。

制作小样时，只重新渲染镜头文件、时长、种子或该镜用到的同步点有变化的镜头，其余片段复用后再拼成完整小样。单镜试看不更新完整小样。

技能包不再附带示例成片。风格说明保留，制作仍从用户自己的影片开始。

## 升级方式与版本

三种原生插件清单和 marketplace 从 0.21.0 升至 0.22.0；导演流程文档从 1.19.0 升至 1.20.0。引擎包保持 0.2.0。

原生插件通过原安装渠道更新并重新加载；其他 Agent 使用正式发布时附带的 `wukong-animation-agent-skills-v0.22.0.zip` 和 `SHA256SUMS`，校验后按原安装参数升级。发布不会自动替换每位用户的本地副本。
