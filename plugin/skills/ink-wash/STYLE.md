# 水墨写意 · Chinese Ink Wash

> 墨分五色，计白当黑。画面靠"留白"呼吸，靠"笔势"运动。

适合：诗意短片、品牌片头、人文叙事、节气 / 节日、慢节奏画外音
不适合：快节奏广告、数据密集讲解、搞笑段子
画幅：16:9、9:16 · 时长：15–60s

## 1. 风格本质（先读这一段）

- **意在笔先**：先想清楚这一镜要表达什么情绪，再动笔。宁可少画，不可多画。
- **计白当黑**：留白本身就是画面的一部分，**每一帧留白 ≥ 40%**（`wka qc` 会量）。40% 是下限，不是越多越好：「少画」是每一笔都有用，不是画面空。每帧仍要有前后层次（近处的枝、芦苇，中间的主体，远处的山、雾），主体之外有陪衬。
- **以线立骨，以墨造韵**：轮廓靠有粗细变化的笔线，体积和氛围靠墨色深浅与晕染。
- **动即是"写"**：画面中的运动，本质上是笔在纸上行走、墨在纸上晕开，而不是物体被"移动"。

## 2. 色彩

只用墨色和纸色，加一点点朱砂。代码里用 `wk.ink.palette`。

| 名称 | 用途 | 值 | palette |
|---|---|---|---|
| 宣纸 | 背景底色（**绝不用纯白**） | `#F2EDE3` | `paper` |
| 焦墨 | 最重的点睛、舟身、题字 | `#141414` | `jiao` |
| 浓墨 | 主体轮廓 | `#2B2B2B` | `nong` |
| 重墨 | 次要结构、近山 | `#4D4D4D` | `zhong` |
| 淡墨 | 中景山、水纹 | `#8C8A86` | `dan` |
| 清墨 | 远山、雾 | `#C9C4BA` | `qing` |
| 朱砂 | 只用于印章 / 一处点睛 | `#B22C22` | `zhusha` |

- 朱砂面积 **≤ 画面 3%**，全片最多 **2 处**。
- 不使用任何其他颜色、阴影、发光、渐变色块。
- 墨与纸一律 `multiply` 叠加（积木内部已处理），让墨"吃"进纸里。

## 3. 构图

- **三远法**：高远（仰望山峰）、深远（层层山谷）、平远（江面远眺），每一镜选一种。
- **散点透视**：横向镜头像展开"长卷"，不做 3D 透视推拉。
- 主体放在 **黄金分割点或画面一角**，不居中。
- 远中近三层：近景重墨、中景淡墨、远景清墨，越远越淡、越虚；山脚入雾。
- 9:16 竖屏改用"立轴"构图：上留天、下留地，主体在中下部。

## 4. 技法（对应的积木见 TECH.md）

### 4.1 宣纸 → `wk.ink.paper(ctx, s)`
低频斑驳（±2%）+ 纤维 + 细颗粒。只生成一次并缓存。

### 4.2 笔触 → `wk.c2d.brush(ctx, pts, {...})`
- **起笔**由细到粗（`taper[0]`），**行笔**宽度轻微抖动，**收笔**收细（`taper[1]`）。
- **飞白**（`dry`）：每根笔毛含墨量不同，沿笔画逐渐跑干，干处留下顺着笔势的长白缝。
- **洇边**（`bleed`）：笔画外侧一圈极淡的晕。
- **写出来**（`progress`）：0→1 即一笔从起笔写到收笔。

### 4.3 墨滴晕开 → `wk.ink.drop(ctx, {x, y, r, density})`
WebGL shader：不规则边缘（极坐标噪声）、中心浓边缘淡、颗粒、**边缘水线**。
半径用 `cubicOut` 增长：先快后慢，最后停住。

### 4.4 山石 → `wk.ink.mountain(ctx, {...})`
- 山脊线由 1D fBm + 不对称主峰生成，两端收到地面。
- 山体淡墨晕染，从峰顶往下渐淡入雾；山脊用断续的干笔勾勒。
- 皴法：沿山体向内的短促斜笔（披麻皴的简化），从山脊向山脚递减。

### 4.5 雾、水
- 雾 → `wk.ink.mist`：用宣纸色画的柔和椭圆带，每秒漂移 ≤ 1% 画宽。
- 水 → `wk.ink.ripples`：只画几笔横向淡墨，其余全部留白。**水是"留"出来的。**

### 4.6 题字与印章
- 题字 → `wk.ink.inscribe(ctx, '题诗文字', {x, y, size, progress})`：竖排、右起，逐字自上而下写出，每字 0.3–0.5s。
- 印章 → `wk.ink.seal(ctx, {x, y, size, text, progress})`：朱砂白文方印，边缘斑驳；
  放大 1.08 → 1、透明 → 不透明，用时约 0.25s，**不回弹**。

## 5. 运动语言

| 要 | 不要 |
|---|---|
| 慢、匀、有呼吸感 | 快切、频闪、抖动 |
| `sineInOut` / `cubicOut` | 弹簧回弹、overshoot |
| 镜头横移如展开长卷（每秒 ≤ 4% 画宽） | 3D 推拉、旋转镜头 |
| 墨晕开、笔写出、雾散去 | 物体平移飞入、缩放弹出 |
| 镜头之间连续（同一幅画）或墨晕 / 雾遮转场 | 硬切超过 2 次 |

一镜 3–8 秒，一个动作完成后**停留至少 1 秒**再进入下一个（"留白"在时间上也成立）。

## 6. 声音

- 首选古琴式拨弦（`synth.qin`）、流水（`synth.water`），或几乎无声。
- 五声音阶（如 D 商调：D E G A C），音要稀疏，允许 2–3 秒完全静默。
- 人声语速放慢，句与句之间停顿 ≥ 0.8s。
- 印章落下配一声轻"笃"（`synth.knock`），与画面共用同一个声音同步点。

## 7. 禁忌清单

- 不要纯白背景，不要纯黑背景。
- 不要铺满画面，不要每个角落都有东西。
- 不要矢量感很强的均匀描边（像图标、像 PPT）。
- 不要阴影、发光、霓虹、渐变色块。
- 不要出现除朱砂以外的颜色。
- 不要模仿特定画家或特定作品的具体画面，用通用技法表达。

## 8. 示范片规格

### 《寒江》`examples/hanjiang/` · 12 秒 · 16:9 · 平远

三镜画的是同一幅画（场景写在 `shots/common.js`），镜头间没有硬切；全片横移 0.8% 画宽/秒，第 8 秒停住。

| 镜头 | 时间 | 画面 | 技法 |
|---|---|---|---|
| s01 | 0–4s | 远山清墨淡入，近岸淡墨山晕染成形，山脚一点墨石晕开 | §4.4 山石 · §4.5 雾 · §4.3 墨滴 |
| s02 | 4–8s | 江面几笔水纹写出，右下一叶小舟写成，停住 | §4.5 水 · 小舟 |
| s03 | 8–12s | 右上竖排题字「孤舟蓑笠翁」逐字写出，落「寒江」朱砂印，留白收尾 | §4.6 题字与印章 |

声音：古琴三声（D3 → A3 → G3）+ 极轻流水，落印一声"笃"。`wka qc` 实测：最少留白约 91%，朱砂远低于 3% 上限，硬切 0 次。
它同时是冒烟测试的示范片（`tests/smoke/`），改动画面后要重新生成基准图。

## 9. 交付前质检

- [ ] 每一帧留白 ≥ 40%（`wka qc`）
- [ ] 至少能看出三种墨色层次（浓 / 淡 / 清）
- [ ] 笔线有粗细变化，有起笔和收笔，干处有飞白
- [ ] 墨滴晕染边缘带"水线"
- [ ] 朱砂 ≤ 2 处、面积 ≤ 3%（`wka qc`）
- [ ] 没有弹跳、没有 3D 旋转、硬切 ≤ 2 次（`wka qc`）
- [ ] 同一种子渲染两次，画面逐帧一致
- [ ] 截任意一帧当静态画来看，也成立
