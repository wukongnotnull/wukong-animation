# v0.14.0 · 横竖改版与桌面插件支持

本版对应历史提交 `8daae3e`（完整 SHA 以标签为准）。该提交的插件清单当时已是 0.14.0，但尚未创建 GitHub Release；本次按维护者要求补发。发布时间为实际补发时间，不回填历史发布日期。

## 变更

- **横竖改版**：在 film.json 声明主版及 variants，用同一套镜头和声轨制作副版；render/still/animatic/qc/subtitles/final 支持按画幅处理，`final --aspect all` 依次输出各版本。[#90](https://github.com/wukongnotnull/wukong-animation/pull/90)
- **主版保护**：终审时保存主版定稿，副版制作前检查主版变化，生成比对报告并识别过期副版。
- **改版流程**：第 14 道工序及审片节点用于副版，剪映草稿顺延到第 15 道；既有制作进度按 flow 4 迁移。[#91](https://github.com/wukongnotnull/wukong-animation/pull/91)
- **桌面插件入口**：提供通用 Agent Plugins 清单、Codex 兼容清单及 film/setup/styles 技能入口，适配当前宿主可用的提问工具和文件路径规则。[#92](https://github.com/wukongnotnull/wukong-animation/pull/92)

## 升级与边界

- 插件 0.14.0，制作流程 v1.12.0，引擎/依赖仍为 0.2.0。
- 这是历史版本，不包含 v0.15.0 的累计切点修复、词级同步、字幕预检、阶段恢复与交付核验。需要这些改进时使用 v0.15.0。
- 历史提交已有 lint/smoke CI 记录；本次核对标签对应的源清单和不可变提交，补发不修改历史代码。实际宿主技能发现及音视频播放不因补建 Release 而被视为已验证。
