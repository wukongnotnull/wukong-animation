# v0.26.4 · 优化剧本人声稿与分镜分工

- 剧本「人声文案」按语意和朗读停顿分行。工作台显示这些换行，跨行批注仍可定位到原文。
- 「人声文案」标注全部台词的汉字总数。改稿后重新统计。
- 屏幕文字的原文、排版和停留时间由分镜稿逐镜决定。分镜的台词在每镜的「人声」单元格内连续书写。
