# 减少工作台占用影片写入锁的时间

工作台浏览应优先读取已登记版本。正式制作完成后，浏览器首次刷新可以复用制作命令留下的观察记录；项目没有变化时无需争取影片写入锁。进程正在制作时，工作台展示最近一次登记的版本，正式提交继续等待制作完成。

自动抓取时，每次观察只读取及计算一次共用文件的摘要。已有快照的来源和对象版本都未变时，自动抓取复用该快照。来源变动、文件替换或对象损坏时重新进行内容检查。观察记录保存在可再生缓存里，旧工程或缓存缺失时自动重新建立。当前来源的解析、依赖摘要和历史版本 ID 沿用现有规则。

显式抓取、核对、签批继续读取实际内容并检查历史快照。已有版本、批注、变更检测及历史项目只读规则继续适用。制作中已记录的成果、正式合成流程和影片引擎版本按现有流程管理。

验收覆盖连续浏览无需加锁、CLI 产出后的首次刷新无需二次抓取、文件变化后登记新版、单文件及共享依赖摘要复用，以及同尺寸改写或快照损坏后拒绝复用。
