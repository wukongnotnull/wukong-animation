# 工作台文档内媒体与链接

- 排版阅读直接显示图片、视频播放器和音频播放器，包括分镜表单元格中的媒体链接。图片按需载入，音视频点播放时加载。媒体链接可收起预览，收起时暂停播放。
- 已登记的本地文件链接使用原有工作台入口打开，以文档位置解析同一影片内的路径，支持中文和尖括号路径。普通 HTTP/HTTPS 链接新开标签页。
- 所有本地媒体从已有的交付版本接口读取。原文模式保留完整 Markdown。缺失、未登记、跨影片或不支持的协议保留原引用。历史文档缺少关联本地文件版本时保留原引用。
- 验证正文和表格中的图片、媒体实际播放、原文模式、本地文档跳转、网页链接及无效地址。文字和镜号仍可定位。
