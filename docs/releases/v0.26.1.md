# v0.26.1 · 工作台批注、测试样片与全屏预览修复

> 插件版本 v0.26.1；制作流程版本 v1.24.0；工程协议 FLOW 8。

本次补丁集中修复工作台的历史批注展示、测试样片归类和全屏预览体验，无新增运行依赖。

## 历史批注

- “已发送的批注”按发送顺序倒序显示，保留定位、正文、版本和时间。
- 移除待办、已完成、确认解决等状态分组和数量，仅显示批注总数；不同处理状态采用相同卡片样式。
- 本次只调整历史列表展示，原有批注记录和对话中的返修、签批流程保持兼容。

## 测试样片

- 修复主画幅的局部小样被归到“08 调整画幅”的问题。例如主画幅为 9:16 时，`局部小样-9x16/` 中的片段现在自动归到“06 制作小样”的参考资料中。
- 测试样片采用“局部小样 s01”“局部原画质 s01”等名称，副画幅样片仍归到第 8 道。
- 已登记的同一文件继续使用原有记录，不重复添加；局部样片不代替完整小样的审阅与签批。

## 全屏预览

- 全屏视频按可用屏幕高度等比放大，图片解除普通预览的高度限制。
- 全屏区域右上角新增“退出全屏”按钮，点击或键盘聚焦后按 Enter 即可退出，随后焦点回到“全屏预览”。
- 普通预览时隐藏退出按钮；预览内容更新时保留按钮节点和键盘焦点。

## 兼容性与升级

制作流程仍为九道工序、最多八个审片节点，工程协议仍为 FLOW 8。本次不增加工程迁移，也不自动改写影片文稿或签批记录。

原生插件通过原安装渠道更新并重新加载；关闭旧工作台后，用新版插件重新打开。其他 Agent 下载本次发布的 `wukong-animation-agent-skills-v0.26.1.zip` 与 `SHA256SUMS`，核对校验和后按原安装参数升级。

## 验证

- 137 项相关测试全部通过，覆盖工作台单元与集成、主画幅与副画幅样片归类、桌面插件、便携安装和升级诊断。
- Chromium 浏览器实测浅色、深色全屏进入与按钮退出、普通模式隐藏、键盘退出及预览重绘后的焦点保留；文档搜索交互回归。
- `npm run lint`、发布包构建与 SHA-256 校验。Firefox / Safari 未作实测。
