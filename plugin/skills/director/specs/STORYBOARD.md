# 分镜表填写规范（storyboard.md）

> `storyboard.md` 给人看，`film.json` 给引擎用，两者逐镜对应（`film.json` 各字段见 `FILM.md`）。

- **工序**：第 5 道 · 审片节点 ④ 分镜
- **模板**：`engine/templates/film/storyboard.md`，第 3 道 `wka init` 建工程时带出空白稿 `films/<片名>/storyboard.md`
- **流程**：怎么提交、签批被拒怎么办见 `../SKILL.md` 第 5 道
- **示例**：各风格的示范片，如 `ink-wash/examples/chunjiang/storyboard.md`

## 一、表头

总长、画幅、分辨率与帧率、风格、种子、对应的剧本版本号。

## 二、逐镜各栏写法

栏目按观看顺序排：编号信息 → 怎么进这一镜 → 看到什么 → 听到什么。没有内容的栏写"—"。

| 栏目 | 写什么 |
|---|---|
| 镜 | 镜号 `s01`、`s02`……，与 `film.json` 的 `shots[].id`、`shots/sNN.js` 一一对应 |
| 段落 | 这一镜属于剧本的哪一段（起 / 承 / 转 / 合）。同一段可拆成多镜，各段镜头时长之和应与剧本的段落时间一致 |
| 时长 | 默认单镜 3–8 秒，动作完成后至少停 1 秒；风格另有规定的以风格为准。有人声时第 7 道按实测回填 |
| 转场 | 进入这一镜的方式，只能用风格转场表里的名称；第一镜写"—"。硬切要少，`wka qc` 会数 |
| 景别 | 大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 大特写，同时写进 `film.json` 的 `shots[].size`。规则见第三节 |
| 画面 | 观众看到什么，不写代码 |
| 运镜 / 动态 | 镜头怎么移动、画面里什么在动、怎么动、快慢 |
| 屏幕文字 | 剧本「屏幕文字」里的哪一条在这一镜出现、以什么形式出现；剧本里的每一条都要落到某一镜 |
| 人声 | 这一镜的人声文案原文，一字不改。默认画外音（VO，内心独白也算），直接写引号原文；其他类型加标记：`对白（角色）：`出镜说话、`OS（来源）：`画外但在场景里、`同期：`现场原声或采访 |
| 音效 | 只写落在这一镜里的点状音效：同步点名（对应 `film.json` 的 `cues`）、入点时刻（全片时间）、音效类型，如 `亭现 6.2s 轻钟` |

## 三、景别规则

景别决定画面的视觉节奏，`wka signoff --step 5` 会查。

- 按主体占画面的比例判断，不按镜头叫什么：同一幅长卷横移，比例没变就是同一种景别。
- 4 镜及以上，全片至少用 3 种景别。
- 相邻两镜景别不同；同一幅画「连续」转场的两镜除外，但全片仍要满足至少 3 种。
- 表下附一行景别序列，如「远景 → 全景 → 特写」。

## 四、声音铺底

BGM 和环境声通常跨好几镜，不进逐镜表，在表下「声音铺底」按全片时间轴单列。每行写时间段、类别（BGM / 环境声）、内容或情绪、淡入淡出与静音等动作，对应配乐脚本 `audio/build.mjs`。

## 五、取决于风格的栏，查 STYLE.md

这里只定栏目和通用规则，不写任何风格自己的取值。各风格 `STYLE.md` 的一级章节固定，查哪一节都一样：

| 分镜栏 | 查 STYLE.md 哪一节 | 查什么 |
|---|---|---|
| 时长 | 6. 运动语言 · 时长 | 本风格的单镜时长、动作后停多久 |
| 转场 | 6. 运动语言 · 转场 | 可用的转场名称、何时用、硬切限额 |
| 景别 | 4. 构图 · 景别对照表 | 各景别在本风格里画成什么样 |
| 画面 | 4. 构图 | 主体位置、分层、留白、安全区 |
| 运镜 / 动态 | 6. 运动语言 | 怎么动、缓动、速度上限 |
| 屏幕文字 | 3. 文字 | 字体、字号层级、出现形式 |
| 音效、声音铺底 | 7. 声音 | 音效清单与密度、配乐 / 环境声 |

用到哪些技法不进分镜表（客户审的是画面，不是积木），写在镜头文件第一行注释里，用 STYLE.md 第 5 节的技法名，见 `SHOT.md`。
