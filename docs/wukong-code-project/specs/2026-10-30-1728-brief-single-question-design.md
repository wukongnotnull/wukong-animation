# 简报逐题卡片确认

关联：#111；用户在本次会话明确要求“使用提问卡片形式提问用户，一次一问，不要使用一轮多问的形式”。以下为该指令的实施与验收范围。

- 制作简报优先使用当前宿主可用的提问卡片。每次只提交一个问题，一题只涉及一个决定，不在正文夹带其他问题。
- 必须收到当前问题的明确回答后才继续；异步工具返回、预选项、超时与未回复均不能推进。已明确的信息直接采用，按决定依赖关系选择下一题。
- 片名、主画幅/副版、字幕方式/字幕语言、必需元素/禁忌/参考等分别确认；不再执行旧的“一轮问完前沿”。没有卡片工具时，文字后备也一次只问一题。
- 保留简报字段、占位片目录与最终独立签批；不改变渲染、声音、交付或其他制作工序。
- 验收：当前使用的导演、简报规范、宿主说明、术语和入口不存在相反指令；打包与安装契约通过；发布后核对已安装技能包含相同规则。此为指令更新，不新增复述文本的单元测试，不对实际模型在所有宿主中的遵循率作保证。

交付沿本会话已授权的发布/升级流程：插件补丁版0.19.1，导演流程1.17.1；历史spec/变更记录保留为当时决策记录，由本规范覆盖与本需求相冲突的旧规则。
