# 分镜表格式

`storyboard.md` 给人看，`film.json` 给引擎用，两者一一对应。

## storyboard.md

```markdown
# 《晨雾》分镜

总长 12s · 16:9 · 1920×1080 @30fps · 风格 ink-wash · 种子 7 · 文学脚本 v1

| 镜 | 段落 | 时长 | 景别 | 画面 | 运镜 / 动态 | 技法 | 人声 | 音效 | 屏幕文字 | 转场 |
|---|---|---|---|---|---|---|---|---|---|---|
| s01 | 起 | 4s | 远景 | 晨雾笼罩山谷，只露出淡淡的山脊线 | 雾气缓慢向右漂移 | §4.5 雾 | — | — | — | — |
| s02 | 承 | 4s | 全景 | 雾渐散，山腰一座小亭显出轮廓 | 雾带上移变薄，小亭逐笔写出 | §4.4 §4.5 | "雾散时，山就醒了。" | 亭现 6.2s 轻钟 | — | 连续（同一幅画） |

## 声音铺底

| 时间 | 类别 | 内容 / 情绪 | 动作 |
|---|---|---|---|
| 0–12s | 环境声 | 山谷风声 | 0–2s 淡入，全片铺底 |
| 4–12s | BGM | 古琴泛音，空灵 | 4s 淡入，11s 起渐弱至静音 |
```

**表头**：总长、画幅、分辨率与帧率、风格、种子、对应的文学脚本版本号。

**逐镜各栏写法：**

| 栏目 | 写什么 |
|---|---|
| 镜 | 镜号 `s01`、`s02`……，与 `film.json` 的 `shots[].id`、`shots/sNN.js` 一一对应 |
| 段落 | 这一镜属于文学脚本的哪一段（起 / 承 / 转 / 合）。同一段可拆成多镜，各段镜头时长之和应与文学脚本的段落时间一致 |
| 时长 | 单镜 3–8 秒，动作完成后至少停 1 秒；有 VO 时第 7 道工序按实测回填 |
| 景别 | 远景 / 全景 / 中景 / 近景 / 特写，决定画面的视觉节奏；景别变化要服务节奏，避免整片只用一种景别（"连续"转场的同一幅画可以保持景别） |
| 画面 | 写观众看到什么，不写代码 |
| 运镜 / 动态 | 写清楚镜头怎么移动、画面里什么在动、怎么动、快慢（参照风格的"运动语言"） |
| 技法 | 引用 STYLE.md 的章节号，方便写代码时对照 |
| 人声 | 这一镜出现的人声，写文案原文，一字不改。默认是画外音（VO），直接写引号原文；其他类型在前面加标记：`对白（角色）：`出镜说话、`OS（来源）：`画外但在场景里、`同期：`现场原声或采访。内心独白也算 VO。没有写"—" |
| 音效 | 只写落在这一镜里的点状音效：同步点名（对应 `film.json` 的 `cues`）、入点时刻（全片时间）、音效类型，如 `亭现 6.2s 轻钟`。没有写"—" |
| 屏幕文字 | 文学脚本「屏幕文字」里的哪一条在这一镜出现、以什么形式出现；没有写"—" |
| 转场 | 连续 / 墨晕 / 雾遮 / 硬切（硬切要少，风格 QC 会数） |

**声音铺底**：BGM 和环境声通常跨好几镜，不进逐镜表，在表下按全片时间轴单列。每行写时间段、类别（BGM / 环境声）、内容或情绪、淡入淡出与静音等动作，对应 `audio.build` 配乐脚本。

## film.json

```json
{
  "title": "晨雾",
  "style": "ink-wash",
  "size": [1920, 1080],
  "fps": 30,
  "seed": 7,
  "scripts": ["shots/common.js"],
  "shots": [
    { "id": "s01", "file": "shots/s01.js", "duration": 4, "note": "晨雾山谷" }
  ],
  "cues": { "亭现": [6.2, 6.6] },
  "audio": {
    "build": "audio/build.mjs",
    "voice_source": "user",
    "voices": [{ "text": "雾散时，山就醒了。", "at": 4.5, "cue": "第一句", "file": "audio/voice/01.wav" }],
    "tracks": []
  },
  "export": { "formats": ["mp4"], "name": "chenwu" }
}
```

| 字段 | 说明 |
|---|---|
| `seed` | 全片随机种子。换种子 = 换一版"笔迹"，构图不变 |
| `scripts` | 片内公共脚本（多镜共用的场景画法），在镜头文件之前注入 |
| `shots[].duration` | 秒。第 7 道工序按 VO 实测时长回填 |
| `cues` | 声音同步点 `名: [入点, 出点]`（全片时间，秒）。VO 同步点由 `wka soundtrack` 自动写入，音效同步点手写 |
| `audio.build` | 配乐脚本，导出 `default async ({synth, duration, outDir, shots, cues}) => [{file, start, gain}]` |
| `audio.voice_source` | 人声素材来源（第 6 道工序，审片节点④）：`user` 用户自供录音 / `ai` AI 配音 / `none` 无人声 |
| `audio.voices` | 人声文案，画外音、对白、同期声都写在这里；`user` 时每条用 `file` 挂接录音；`ai` 且没装 TTS 时按每秒 3.6 字预估同步点 |
| `voices[].kind` | 人声类型，对应分镜「人声」栏的标记：`vo` 画外音（默认，含旁白、内心独白）/ `dialogue` 对白 / `os` 画外但在场景里 / `live` 同期声。`live` 是现场原声，AI 配不出来，必须挂接 `file`；`voice_source` 为 `ai` 时，其余条目照常 AI 配音 |
| `voices[].speaker` | 说话的人或声音来源，对应标记括号里的内容，如 `对白（老者）` 写 `"speaker": "老者"` |
| `export.formats` | 已注册的导出器：`mp4` / `gif` / `png-seq` |

完整字段见 `engine/schemas/film.schema.json`。旧字段名 `voiceover` / `vo_source` 仍能读取，`wka soundtrack` 会提示改成新名；新旧两个名字同时出现会报错。
