# v0.15.0 · 长片同步、恢复与交付可靠性

本版在 v0.14.0 的横竖改版和 Codex / ChatGPT 桌面插件支持基础上，加入三批客户体验优化。v0.14.0 此前只更新了源码清单，本次先为当时的提交 `8daae3e` 补发对应 Release，再发布 v0.15.0；历史版本不包含后续优化。

## 新增与改进

- **横竖改版**：同一套镜头与声轨制作主版/副版，支持 `--aspect` 与 `final --aspect all`；副版缓存、字幕、成片及草稿分别命名，保留主版定稿保护。[#90](https://github.com/wukongnotnull/wukong-animation/pull/90)、[#91](https://github.com/wukongnotnull/wukong-animation/pull/91)
- **桌面插件**：提供通用 Agent Plugins 清单、Codex 兼容清单及 film/setup/styles 入口，按宿主能力处理提问与文件交付。[#92](https://github.com/wukongnotnull/wukong-animation/pull/92)
- **长片声画时间轴**：高清、小样及两条管线按累计切点分配帧数；实测片段、拼接与交付帧数，避免逐镜取整导致的累计漂移。[#94](https://github.com/wukongnotnull/wukong-animation/pull/94)
- **词级同步与字幕预检**：词锚点绑定音频/原文，明确人工、对齐和估算来源，提供帧与音频抽查材料；保护英文术语，默认保留手改 SRT/英文稿；按实际字框检查安全区和声明的重要区域，生成亮暗底及实片样张。[#95](https://github.com/wukongnotnull/wukong-animation/pull/95)
- **恢复与交付**：安全复用主版成功证明，阶段日志标明画幅；新增 `resume`、`delivery`，完整产物复用、缺失补做；纯剪映草稿不拼全片，完成回执避免中断后重复导出，用户编辑受保护；同一批准 ID 重试不重复存档。[#96](https://github.com/wukongnotnull/wukong-animation/pull/96)
- **减少重复提问**：简报已选草稿就直接准备导出，已选只交成片就直接结束，交付形式未明确才询问。真实审片节点继续等待用户。
- **审听与 QC**：按当前混音记录开场/段落/转折审听；QC 原始测量与人工处置分开，接受备注不能绕过技术硬错误；写草稿前说明整体响度与尾部淡出差异。
- **特殊路径**：修复中文、空格、括号、`#`、`%` 路径下的文件 URL 与字体引用。

## 升级说明

- 插件各宿主清单统一为 **0.15.0**；制作流程 **v1.13.0**。引擎及 npm 依赖版本不变，已有依赖可继续使用；新环境仍需执行 setup。
- 保留既有 film.json 与流程迁移。渲染/验证条件变化时必要缓存会失效；旧项目缺少当前时间轴或字幕预检证据时，按提示重新生成证据，再签批。
- 既有 SRT 与英文稿默认只检查；`subtitles --force` 会覆盖手改。重复草稿导出会核实回执；草稿被用户编辑时保留原件，明确要另导新版才使用 `final --formats jianying --force`。
- 不自动重写客户镜长、录音或已签批快照，不覆盖旧剪映草稿。草稿保留分轨音量和已烘焙闪避，整体母带响度及统一尾部淡出仍需在剪映核对。

## 验证与边界

发布前重新执行 lint、安装契约、全量测试及示范片冒烟检查；结果记录在发布 PR。

宿主实际点击/播放尚未完成验证，相关项保持 `not-tested`：当前工具禁止控制 Codex 原生窗口，浏览器拒绝 file:// 协议；其他未实测宿主也不宣称已通过。文件存在性、内容签名和真实媒体检查不等同于宿主播放成功。配乐听感、画面语义及未知遮挡继续由实际审听/审片确认。[#93](https://github.com/wukongnotnull/wukong-animation/issues/93) 保留开放跟踪人工验证。
