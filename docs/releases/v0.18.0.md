# v0.18.0 · 最终交付闭环

本版让最终交付按已确认的承诺汇总，并将验收绑定到实际文件版本。缺项仍保留可用成果，旧签批和手改草稿不会被误当作当前全部通过。

## 改了什么

- **精简交付清单**：`wka delivery <片目录> --final --host codex|claude|generic` 默认覆盖全部确认画幅，分别输出视频、字幕、草稿及其入口、阻塞和下一步。技术材料进入独立审计附录，最后一次“只导草稿”命令不再取消视频承诺。
- **验收绑定版本**：既有13/15道支持 `--delivery-revision <完整摘要>`；14道在完整来源及实际高清生成证据匹配时继承认可，并明确未实际打开高清。工序和审片数量不变。
- **保留手改与历史**：完整目录快照绑定保存并退出剪映后的当前内容，验收后磁盘变化转为待复核；旧记录缺少确切绑定时仅显示历史认可。当前复核可追加人工快照，不改原导出marker，不覆盖旧history或草稿。
- **按产物核验来源**：英文、字幕版式、画幅覆盖和词锚点分别影响相关产物；动态/外部来源、字体或工具身份不足时明确待核实。文件hash不证明实际播放或native显示通过。
- **登记可恢复**：查询不触发渲染、字体下载或state迁移；CLI仅保存清单与审计。证据保存失败不抹去成功产物，`--final --record` 可重试已有完整证据，不补造批准。取证失败也不额外阻断原有小样渲染。

本版实现见[PR #107](https://github.com/wukongnotnull/wukong-animation/pull/107)，其他制作体验改进继续由[#93](https://github.com/wukongnotnull/wukong-animation/issues/93)跟踪。

## 升级与使用

- 通用、Codex、Claude和marketplace清单统一升至**0.18.0**。导演文档流程v1.16.0；引擎及npm依赖仍为0.2.0，已有共享依赖可继续使用。
- Codex原生Git来源刷新指定marketplace后，通过宿主支持的安装/更新流程获取版本；新聊天中核对加载版本。Claude沿原marketplace更新。
- 其他Agent下载本版 `wukong-animation-agent-skills-v0.18.0.zip` 和同次发布的 `SHA256SUMS`，验证后按相同agent、scope、project执行upgrade。不会承诺所有宿主自动更新，也不直接改写插件缓存。
- `delivery --final` 返回0仅表示请求范围内全部必需产物已核实且当前验收有效；返回2仍可能有部分成果；返回1表示参数/读取/报告写入故障。单画幅结果不代表整片。
- 不自动迁移客户工程的历史验收，不自动重渲或覆盖草稿。旧中间delivery、resume、缓存复用与原signoff调用保持兼容；无revision的旧签批只代表流程历史。

本机全量413项测试、lint、两支示范片9张冒烟基准图均通过。隔离CLI实际完成视频、SRT、剪映native草稿、主版签批、手改后版本绑定与再次变化核验。原片只读验证10项承诺产物入口，工程、两个草稿及字体缓存未变。[验收报告](../wukong-code-project/reports/2026-10-30-final-delivery-loop-validation.md)
