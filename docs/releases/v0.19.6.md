## 新增升级诊断

用户可说“用 wukong-animation 检查插件版本和升级状态”。也可从实际安装目录运行：

```bash
node "<插件根目录>/engine/bin/wka.mjs" check --upgrade
node "<插件根目录>/engine/bin/wka.mjs" check --upgrade --json
```

输出插件/引擎版本、实际路径、包格式、依赖来源与身份，以及对应渠道的升级指引。诊断离线只读；不能确认远端最新版本或当前聊天是否重载时明确显示未知。其他 marketplace 路径失效或无法识别的配置只给警告，不自动修改配置、安装依赖或执行更新。原来的普通 check 继续用于制作环境检查。

## 发布流程保护

每个 PR 都产生稳定的 merge-gate，必要检查失败、取消、缺失或意外跳过时不能通过；纯文档按白名单跳过媒体检查。main 已要求 PR、最新基线及该门禁成功，管理员同样受约束，禁止强推/删除。已用真实故障 PR 验证管理员合并请求被 HTTP 405 拒绝，并验证恢复后可合并状态正常。
