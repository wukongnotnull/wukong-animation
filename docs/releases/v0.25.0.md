# v0.25.0 · 剧本后独立制作人声

> 发布说明草稿：建议插件版本 v0.25.0、制作流程版本 v1.24.0，待版本确认后发布。

「制作人声」成为「编写剧本」之后、「规划镜头」之前的独立工序和试听签批节点。现在无需先编排镜头，就能接入完整用户录音、核对原稿、人工确认句段定位并完成签批。制作流程共九道工序，最多八个审片节点；工作台、CLI、交付清单与导演规范同步。

## 人声验收

- 只有明确没有任何人声才跳过；旁白、对白、OS 和同期声都属于人声。需要人声却没有录音时，后续签批会被阻塞。
- 句段必须人工试听确认并应用，自动匹配不能代替确认。默认生成逐词表；待确认的词不阻塞人声签批，但不能被镜头引用。
- 人声批准绑定录音内容、剧本和录音内句段时间。整体前移或后移录音保留人声批准，但须重新应用全片同步点，并复验受影响的分镜和后续交付。改录音、改稿或改录音内句段定位需要重新验收。
- 按完整录音实长编排画面，不擅自裁剪或变速。声稿冲突或录音超出明确片长限制时，由用户决定处理方式。
- 配乐、音效、环境声和完整混音仍在制作小样阶段完成。人声由用户提供，不增加 AI 人声、TTS 或字幕能力。

## 兼容性与升级

新工程采用 **FLOW 8**。旧 FLOW 7 及更早工程只读留档，本次不提供迁移，也不继承旧签批；继续创作时另建新工程并复用素材。

原生插件通过原安装渠道更新并重新加载；关闭旧工作台后，用新版插件重新打开。其他 Agent 下载本次发布的 `wukong-animation-agent-skills-v0.25.0.zip` 与 `SHA256SUMS`，核对校验和后按原安装参数升级。
