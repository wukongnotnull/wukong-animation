# v0.24.2 · 工作台默认浅色与项目链接优化

工作台首次打开时默认使用浅色主题。手动切换浅色或深色后，刷新及下次打开继续使用已保存的选择；本地存储不可用时仍可切换主题。

打开包含 `film` 参数的工作台链接后，先加载指定影片，再从地址栏隐藏该参数；其他查询参数保持不变，刷新后仍恢复刚才打开的影片。只读影片同样保留当前选择；加载失败时保留原链接，便于重试。

## 升级

原生插件通过原安装渠道更新并重新加载；已打开的旧工作台需关闭后，用新版插件重新打开。其他 Agent 下载本次发布的 `wukong-animation-agent-skills-v0.24.2.zip` 与 `SHA256SUMS`，校验后按原安装参数升级。
