本版包含 [审阅工作台 #128](https://github.com/wukongnotnull/wukong-animation/pull/128) 和 [主播实录字幕核验 #130](https://github.com/wukongnotnull/wukong-animation/pull/130)。

## 交付物审阅工作台

在已更新插件的桌面环境中说“用 wukong-animation 打开这个项目的审阅工作台”，即可在本机浏览器按制作阶段检查文字、图片、音频、视频和专用交付文件。

- 待审总览支持搜索、筛选、定位问题和继续上次审阅。
- 批注绑定具体版本及文字、图片位置或音视频时间；可查看历史、比较版本并按阶段签批。
- 意见草稿与正式提交分开保存。返修后由用户检查对应版本并确认复验，生成新版不会自动消除阻塞。
- 支持宽窗与窄窗布局、更新提示和断线恢复。素材保留本机，不需另建账号。

工作台提供预览与审阅，不提供剪辑。需要能访问本地终端和文件的桌面环境、Node.js 与浏览器。

## 主播实录字幕与成片核验

显式启用主播字幕模式后，可使用已经校对的 SRT，按各画幅的镜头时间轴定位，检查单行、重叠和插播留空冲突。

最终烧录 MP4 会逐句检查首、中、末帧。发现缺字时保留成片并阻止交付；无法确定的结果需要针对当前文件人工复核，重新导出后旧确认失效。此核验检查字幕字形是否出现，不代替内容语义、声音同步和完整观感验收。

## 升级

三种原生插件清单和 marketplace 统一升级至 0.20.0；导演流程文档升级至 1.18.0。引擎包仍为 0.2.0，工程 flow 5、15 道工序和 12 个审片节点保持。

原生插件通过原安装渠道更新；其他 Agent 下载本版的 `wukong-animation-agent-skills-v0.20.0.zip` 与 `SHA256SUMS`，校验后按原安装参数执行升级。宿主更新后需重新加载插件；发布不会自动替换每位用户的本地副本。

历史成片、签批与审阅记录保留；实现身份变化可能使旧缓存或证据需要重新核实。工作台历史无法恢复接入前已覆盖的文件。每批视频生成仍需用户单独确认。
