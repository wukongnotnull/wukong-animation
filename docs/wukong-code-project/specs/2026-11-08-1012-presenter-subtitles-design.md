# 主播实录字幕与成片核验

Status: Confirmed
Date: 2026-11-08
Source: grilling

## 问题与目标

影片曾出现字幕样张有字、导出的 MP4 无字。主播版还需要一句字幕对应实录时间，插播留空，并能从字幕找到所有覆盖的镜头。

## 架构与组件边界

复用项目 SRT、量化镜头时间轴、字幕审阅和正式交付入口。启用主播实录字幕后，导出前校验输入并生成分镜定位表，最终烧录 MP4 从实际输出取帧核验。人工复核作为当前文件的独立证据。

## 接口、数据与行为

- 主播实录模式显式启用。以指定 SRT 的文字、断句和成片时间码为准，缺文件时提示补齐。
- 成片时间轴可标记任意留空区间，包含局部镜头。禁止多行、重叠和进入留空区间。错误列出条目、时间和对应镜号，剪辑者自行修改源 SRT。
- 单条字幕允许跨普通切点，定位表给出每个覆盖镜头及交叠时间。横竖版可以复用输入或各自指定字幕与留空区间，各自定位和核验。
- 核验每句首个应显示帧、中间帧及最后一个应显示帧，重复帧只查一次。报告提供实际帧、时间码、镜号和成片入口。

## 约束、兼容性与非目标

未启用模式的项目继续沿用现有流程。无字幕输出和外挂字幕不标记为烧录已验证。首批不包含自动转录、画面语义推断、音效、主播窗优化和发布升版。

## 错误处理与运维

已确认字幕缺失时，保留成片供排查，暂停通过交付。机器无法确定时记录待人工核对。人工结果只绑定当前画幅的当前导出文件及当前核验依据，重导后需复验。

## 验收标准与测试

验证同一时刻一条主播字幕、跨镜定位、插播冲突拦截、横竖版复用与独立覆盖。用最终编码 MP4 验证正常显示和实际漏字两条路径，并覆盖不确定结果与旧人工结果失效。未启用的字幕工作流须继续通过回归检查。
