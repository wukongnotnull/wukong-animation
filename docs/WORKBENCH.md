# 本地审阅工作台

在包含本次功能的插件中说：**“用 wukong-animation 打开这个项目的审阅工作台。”**

插件会在浏览器打开本机页面。无需另建账号，素材留在电脑上。终端服务需保持运行；停止后，重新启动并使用新的完整链接。当前开发改动未自动发布，已安装的 0.19.6 发布包不会因此获得新界面。

## 怎么审阅

1. 顶部选择影片，左侧选择制作阶段和交付物。
2. 中央阅读文档、查看图片或播放音视频。视频下方可以定位镜头和时间，但不能剪辑；文字只读。
3. 选中文字、点击图片，或点击“标注当前时间”，在右侧留下具体意见。音视频区间可以填写起点与终点；总体意见不用定位。
4. 每项检查完成后点击“已检查当前版本”。本阶段所有必需项齐全且阻塞意见解决后，再点击“通过本阶段”。也可以填写结论并点击“需要修改”。
5. 回到对话说“处理工作台里的待办”，插件会读取意见和准确位置，不必复制每条意见。保存批注不会启动生成。

“查看版本”可切换历史；旧版通过不代表新版通过。来源变化会显示“需要复核”，历史内容仍保留。刷新交付物会保留正在查看的版本，请在版本列表选择新的当前版本。

剪映草稿等专用工程显示文件组成和检查状态，通过“定位原文件”前往系统文件管理器，再用专用软件检查。定位成功不等于已经打开或验收。

## 给制作助手的入口

下面 `wka` 指当前安装插件的 `node <插件根目录>/engine/bin/wka.mjs`；由技能根据实际安装路径解析，不使用作者电脑路径。

```text
wka workbench <项目或片目录> --open
wka workbench <片目录> --capture
wka workbench <片目录> --pending
wka workbench <片目录> --register <文件或目录> --step 3 --label "美术方案"
```

支持 `--port N` 指定本机端口；默认选择可用端口。自定义交付物可用 `--depends "来源路径1,来源路径2"` 声明来源，依赖路径以片目录为基准。外部交付物必须明确登记，页面不能任意浏览电脑文件。

制作助手应在覆盖文字等交付物前 capture，写好后再次 capture。接入后的引擎制作命令也会保存交付版本。美术方案及选定理由保存到 `visual-direction.md`；人声来源和试听选择保存到 `review/人声来源.md`。与原命名不同的旧材料可登记，不需要为了使用工作台重做影片。

## 保存、故障与边界

- 审阅账本：片目录下 `.wka/workbench.json`。历史内容：`.wka/workbench/objects/`，按内容去重并排除出 Git，保留在本机。备份影片时应同时备份这两处。
- 工作台不能找回从未保存、已被覆盖的旧内容，也不会把当前文件冒充历史版本。历史存储会占用磁盘；空间不足时应先处理，不能删除证据后继续假报保存成功。
- 文件缺失、来源变化、检查不通过、其他制作命令正在写入时，页面提示具体原因；处理后刷新。文件存在或可播放都不等于用户已通过。
- 字幕、时间轴、主版保护、最终交付的既有签批条件继续生效。批准已记录但 Git 存档未确认时，回到对话核实存档状态。
- 需要本地 Node.js 环境和可用浏览器。没有本地执行能力的纯聊天宿主不能启动本机服务。专用软件和浏览器格式支持以实际检查为准。
- 不提供剪辑、文字编辑、云端协作或自动生成；视频生成仍按每批单独确认的规则执行。
