# 浏览与推荐动画风格

本文件位于 `<插件根目录>/skills/styles/SKILL.md`。先取得**当前加载的本文件所在目录的真实路径**，再上移两级目录得到插件根目录，不依赖宿主的插件路径变量或固定缓存版本。

1. 读取同包的 `<插件根目录>/catalog.json`。
2. 在有本地终端与 Node.js 20+ 的环境中运行（替换实际绝对路径，保留引号）：

   ```bash
   node "<插件根目录>/engine/bin/wka.mjs" list styles
   ```

   CLI 会补充用户自定义风格及管线兼容状态；不可执行时仍可展示 catalog 中的内置风格，但明确说明尚未检查本机环境与用户风格。
3. 用表格展示序号、名称、分类、适合拍什么、是否可用。区分「已实现」「规划中」和「不可用」，不要把规划中的风格说成已经能拍；已实现也不代表本机渲染依赖已装好。
4. 用户给了关键词时，结合 `keywords`、`best_for` 与 CLI 兼容结果，优先推荐已实现且兼容的风格，最多 3 种；不足 3 种就如实说明，不拿规划项凑数。

本技能只读：不要运行 setup、init-project、brief、init 或 render，也不要自动切换到 film。最后说明用户可以说「用 wukong-animation 按这个风格拍一支短片」开拍，等用户提出制作请求后再进入导演流程。
