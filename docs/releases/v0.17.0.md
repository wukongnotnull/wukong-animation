# v0.17.0 · 字幕制作挪到小样之前

本版调整制作流程：先做字幕，再出小样。小样审片时直接看带字幕的版本，画面和字幕位置一次审完。

## 改了什么

- **工序对调**：第 10 道改为「字幕制作」（审片节点 ⑧ 字幕），第 11 道改为「小样渲染与技术质检」（审片节点 ⑨ 小样）。[#101](https://github.com/wukongnotnull/wukong-animation/pull/101)
- **版式预检**：第 10 道还没有小样，`wka subtitles --preflight` 按 `film.json` 计算时间轴，检查字框、安全区和声明过的内容区，在白、黑、灰底上出样张，写成 `review/字幕预检-版式.md`。报告注明未在实际画面上核对。没有小样时 `--preview` 会报错并提示先渲染小样。
- **小样带字幕审**：第 11 道渲染小样后用 `wka subtitles --preview` 在真实画面上复查字幕。⑨ 小样签批要求当前的小样字幕预检，字幕不压画面的检查仍然保留。
- **返修选项**：⑨ 小样的返修选项为「画面与 QC 问题 / 动作节奏 / 声音 / 字幕位置」。

## 升级说明

- 插件各宿主清单统一为 **0.17.0**；制作流程 **v1.15.0**。引擎及 npm 依赖仍为 0.2.0，已有依赖可继续使用。
- 15 道工序与 12 个审片节点的数量不变，编号有变化。
- 在制作品的进度在读取时自动换算：原第 10、11 道互换编号。只签过小样、还没做字幕的片子，下一步变为第 10 道字幕；字幕签批后要带字幕重新提交 ⑨ 小样。两道都已签过的片子不受影响。已有字幕文件和已签批快照不会被重写。
- Claude Code、Codex、ChatGPT 桌面沿用 README 里的原生命令升级。其他工具下载本版的 `wukong-animation-agent-skills-v0.17.0.zip` 和 `SHA256SUMS`，解压后用同一 agent、scope、project 执行 `upgrade`。

## 验证与边界

发布前执行 lint、全量测试、示范片冒烟和安装契约，结果记在发布 PR。

还没有用真实在制作品完整走过新的第 10、11 道；版式预检只能查 `subtitle-layout.json` 声明过的区域，实际画面上的遮挡仍要在第 11 道人工看。
