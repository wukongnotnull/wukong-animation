# 主播实录字幕实施计划

接入校对过的实录字幕，并在成片交付前提供可定位的画面核验。

Node.js 负责 SRT、时间轴和交付证据。FFmpeg 从最终 MP4 读取检查帧，与干净画面和字幕图层比对。项目显式启用，旧项目沿用现有路径。

1. 为时间轴边界、跨镜、插播和抽样分类编写单测。用 `node --test tests/unit/presenter-subtitles.test.mjs` 验证红绿。
2. 接入项目配置、画幅解析和字幕命令。验证已启用项目的导入、定位表和冲突，以及旧项目的兼容性。
3. 在实际 MP4 编码后、生成交付凭据前验证字幕。验证漏字、待人工核对、人工证据绑定和重导失效。涉及生成视频的测试另行确认。
4. 记录配置和审阅方法。完成定向验证与 lint 后提交。

## 验证结果

- 58 项定向单测通过，覆盖句子时间、跨镜、画幅覆盖、人工复核摘要和交付门槛。lint、生成文档检查及架构检查通过。
- 3 项媒体集成测试通过，覆盖横屏正式导出、竖屏小样、已编码 MP4 的晚一帧和整句漏字。
- 制片项目横竖版共 311 条实录字幕对照 175 镜和五段插播，定位与留空校验通过。现有竖屏正式版只读检查发现部分字幕晚一帧，170 条的中间帧和末帧均可见。第 11 条在 22.400 秒未出现，22.467 秒可见。仅检查旧文件，保留原交付。
