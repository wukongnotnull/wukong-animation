# 声音收尾 实施计划

- spec：`docs/wukong-code-project/specs/2026-10-28-0125-sound-finish-design.md`（#46）
- 目标：`wka soundtrack` 产出带闪避背景音乐、两遍母带到风格响度、并附音效听感审计的声轨。
- 架构：`synth.bed` 生成背景音乐；`duck.mjs` 处理标了 `duck` 的音轨；`loudness.mjs` 两遍 loudnorm；`audit.mjs` 混分轨比电平；`soundtrack.mjs` 串起来。
- 技术栈：Node 20（node:test）、ffmpeg。
- 全局约束（摘自 spec）：没写 `loudness` 的风格目标仍为 -18；不带 `duck` 的音轨、不用 `sfx` 的配乐脚本行为不变；剪映草稿不做响度标准化，只换用闪避后的背景音乐文件。
