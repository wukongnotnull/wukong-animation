# v0.21.0 · 八道制作流程与本地录音定位

发布准备稿：版本号等待用户明确批准，尚未发布。功能与验证依据见 [#133](https://github.com/wukongnotnull/wukong-animation/issues/133) 和[验收记录](../wukong-code-project/verification/2026-11-08-simplified-production-flow.md)。

## 升级前须知

本版弃用旧制作流程。已有制作记录的影片保留为只读档案，原文件、成片、签批和批注保留；不会自动迁移或继承旧签批。需要继续制作时，请另建新影片并复用已有素材，再按新流程审阅。只有录音、原稿、参考图等输入素材的目录不算已开始制作；损坏或不明记录须先恢复。

AI 人声与字幕能力已移除，包括字幕生成、导入、烧录、外挂、核验及剪映字幕轨。画面标题、题字、配乐、音效和环境声仍可制作；历史字幕文件可查看。

## 八道制作流程

| 工序 | 主要交付物 |
| --- | --- |
| 制作准备 | 环境检查结果 |
| 确定方案 | 方案简报 |
| 编写剧本 | 剧本 |
| 规划镜头 | 分镜稿 |
| 制作小样 | 小样视频 |
| 制作成片 | 成片视频 |
| 调整画幅 | 横屏成片／竖屏成片 |
| 导出剪映草稿 | 剪映草稿 |

美术方向随方案简报一起确定。分镜稿安排文字镜头，分镜图按需制作。制作小样整合分镜图、动画、用户人声、混音、剪辑及声画对齐，统一验收完整小样；制作成片合并终版渲染与终审。准备环节不签批，其余保留 7 个审片节点，画幅调整与草稿交付按实际需要执行。

工作台同步显示新工序和交付物，支持查看过程产物与审阅历史。旧项目明确标为只读；工作台继续负责预览与审阅，不提供手动剪辑界面。

## 用户录音与本地台词定位

支持整段和多段录音，不要求用户逐句切好；录音按原文件接入，不擅自删词、截断或变速。需要人声却缺录音时，等待素材再制作依赖该录音的动画与小样；无人声影片正常制作。

首次使用自动台词定位时，按引导准备本地 whisper.cpp 组件和模型。识别在本机 CPU 运行，不上传录音；有稿匹配原稿，无稿识别内容。无法可靠确定、与剧本不符或环境不支持时，说明原因并允许确认或修正时间点；不将估计时间当成已验证定位。原稿、录音或起点改变后，相关定位须重新核实并应用。

修复重复处理录音时仅因同步点排列顺序变化而无意义重写工程文件的问题。

## 升级方式与版本

建议三种原生插件清单和 marketplace 从 0.20.0 升至 0.21.0；导演流程文档从 1.18.0 升至 1.19.0。引擎包保持 0.2.0，新工程使用内部流程标记 flow 6。

原生插件通过原安装渠道更新并重新加载；其他 Agent 使用正式发布时附带的 `wukong-animation-agent-skills-v0.21.0.zip` 和 `SHA256SUMS`，校验后按原安装参数升级。发布不会自动替换每位用户的本地副本。每批视频生成仍需单独确认。

## 验证与限制

本地完整回归首次 534/535 通过；唯一失败已修复，单独授权的 9 项定向复验全部通过。严格剪映 27/27 通过，规范检查通过。桌面与窄侧栏的工作台预览、批注和历史只读已核验。发布分支、PR、main 和标签的新一批 CI 结果将在正式发布前核对并补入 GitHub Release。

实际语音识别仅在当前 Mac 的 CPU 上用既有英文样本验证了有稿与无稿两种方式；Windows/Linux 原生识别运行，以及中文、方言、多人和噪声准确率尚未实测。严格剪映测试验证程序生成和检查草稿，未在剪映桌面软件中人工打开验收。此前的 Windows 文件时间戳观察偶发失败仍由 [#113](https://github.com/wukongnotnull/wukong-animation/issues/113) 跟踪，本版不宣称已修复。
