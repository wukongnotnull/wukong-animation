# v0.26.2 · 修复工作台 localhost 入口

> 插件版本 v0.26.2；制作流程版本 v1.24.0；工程协议 FLOW 8。

打开 `http://localhost:63711/` 时，工作台不再因主机名与 `127.0.0.1` 不同而报 403“仅接受本机工作台的同源请求”。本机根入口现在会临时跳转到工作台的标准 IP 地址，并保留影片选择参数。

## 修复与边界

- 支持当前监听端口的 localhost 根路径 GET/HEAD 文档导航，使用 307 跳转。
- 跳转目标固定为当前服务的 `http://127.0.0.1:<端口>/`，查询参数不能改变目标主机。
- API、静态资源、写入及项目接入控制接口继续使用现有 Host 和同源限制；不增加公网或局域网访问能力。
- 无新增运行依赖；不改变影片目录、工程身份、九道制作流程、签批记录或 FLOW 8。

## 升级

原生插件通过原安装渠道更新并重新加载；关闭已打开的旧工作台，再用新版插件启动。其他 Agent 下载本次发布的 `wukong-animation-agent-skills-v0.26.2.zip` 与 `SHA256SUMS`，校验后按原安装参数升级。
