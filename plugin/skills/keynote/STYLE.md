# 发布会 Keynote · Keynote Launch

> 一页一个观点。大字、深底、一抹橙，界面会动、镜头会推。

适合：产品发布、功能讲解、知识讲解、口播类信息片、片头片尾
不适合：抒情叙事、手绘质感、角色表演
画幅：16:9、9:16 · 时长：15 秒–5 分钟

规范来源：用户的《苹果发布会风格 Keynote 设计规范 16:9》按 2 px/pt 映射到 1920×1080，以及前几支口播动画反复确认下来的默认值。所有数值都在 `scripts/frame.tsx` 和 `scripts/theme.ts`，镜头用 `useFrame()` 读取，不要手写像素。

## 1. 风格本质（先读这一段）

- **一页一个观点**：一镜只讲一件事。要点一次只亮当前一条（`CuePoint`），超过 3 步用 `StepList` 高亮当前步。
- **画面文字不复述旁白**：标题写提炼（「仓库在，记忆就在」），要点写旁白没说出口的那一层，步骤写界面上的原始标签。
- **表达"多"用图形，不用一个大数字**：画 10 个窗口，而不是写"10"。
- **界面用代码重绘**：用户自己的产品界面、截图里打码的区域，一律用代码画（`Shot` + 组件），文案用演示数据。

## 2. 色彩

| 名称 | 用途 | 值 | `color.` |
|---|---|---|---|
| 底 | 背景（叠 40% 透视网格 + 暗角） | `#111111` | `bg` |
| 主文字 | 标题、要点 | `#F5F5F7` | `fg` |
| 次文字 | 副句、注释 | `#B5B5BA` / `#6E6E73` | `fgSoft` / `fgFaint` |
| 容器 | 承托深色元素、重绘界面底 | `#242426` | `container` |
| 强调 | **全片唯一强调色**（Claude 橙） | `#D97757` | `accent` |
| 浅色面 | 重绘的白色界面底 | `#FFFFFF` | `card` |
| 浅色面上的字 | 白色界面里的正文 / 次要字 | `#1D1D1F` / `#626267` | `ink` / `inkSoft` |
| 细边 / 浮层 | 深色面板的 1px 描边；半透明浮层 | `rgba(255,255,255,0.12)` / `rgba(36,36,38,0.72)` | `glassEdge` / `glass` |

- 强调色只用一个；标题里 `[方括号]` 括起来的部分自动上强调色。
- 橙色面积 **≤ 画面 4%**（`wka qc` 会量）；泳道、diff 等数据色（`lanes`、`diffAdd`…）只用于数据本身，不做装饰。

## 3. 文字

| 字体 | 用途 | `font.` |
|---|---|---|
| Inter + 思源黑体（Noto Sans SC） | 标题、要点、标签等所有画面文字；英文数字走 Inter，汉字走思源黑体 | `sans` |
| JetBrains Mono | 代码、命令、配置文件、终端等重绘界面里的等宽内容 | `mono` |

- 只用这两套，不加第三种字体；字幕字体由 `style.json` 的 `subtitles` 决定，镜头里不管。
- **字幕默认中英双语**（口播片，在简报阶段确认）：中文在上、英文在下，同字号白字，中文 Noto Sans SC、英文 Inter（`style.json` 的 `subtitles.font_en`）；`film.json` 的 `subtitles` 写 `"bilingual": true`，英文怎么填见 director 第 11 道。字幕带按两行留的位置，单语时也不往里放内容。
- 字号、字重、行高一律用 `f.type.Txx`，不手写。

字号（横 / 竖，px）与字重：

| 样式 | 用途 | 横 | 竖 | 字重 |

| T02 | 页标题 | 112 | 84 | 600 |
| T03 | L04 标题 | 96 | 84 | 600 |
| T04 | 声明 / 标签 | 64 | 52 | 500 |
| T05 | 要点 | 56 | 46 | 400 |
| T06 | 步骤 / 按钮 | 44 | 40 | 500 |
| T07 | 注释 | 32 | 30 | 400 |

| T09 | 辅助行 | 48 | 36 | 400 |

屏幕文字的出现形式（分镜「屏幕文字」栏写这一列的名字）：

| 形式 | 用途 | 技法 |
|---|---|---|
| 标题 | 页标题、单句标题页、副句 | 「标题」 |

## 4. 构图

安全区：横 (120, 80, 1680×920)，竖 (72, 200, 936×1300)，竖屏避开短视频平台的顶栏、右侧按钮列和底部文案区。字幕底边横 y 1000、竖 y 1500，内容不得进字幕带（单图铺满全屏的细节页除外，字幕叠在图上）。右上角（横 1588,80 / 竖 796,200，212×200）留给出镜小窗：标题宽度横 ≤ 1440、竖 ≤ 700。L04 右图和铺满全屏的图会伸进这个角；开了出镜小窗的片子，小窗直接叠在图上，图里要看的东西（高亮框、鼠标、关键文字）不放在这个角里。

版式母版（`f.layout.Lxx`）：

| 版式 | 用途 | 横屏结构 | 竖屏结构 |
|---|---|---|---|
| L01 | 核心短语 / 开场 / 转场 / 片尾 | 居中一句 + 副句，T01 撑满 | 同，垂直居中偏上 |
| L02 | 产品主图 | 标题 + 大图 1440×584（标题下方到字幕带上方） | 标题在上，图 936×888 |
| L03 | 全宽画面 | 标题 + 全宽图 1680×584，适合长条图 | 同 L02 |
| L04 | 观点 + 画面 | 左标题 / 要点 520 宽，右图 1120×768（上到安全区顶，下到字幕带上方） | 标题在上，图 936×600，要点在下 |
| L05 | 图形 + 声明 | 上图形，下声明 + 注释 | 图形区 936×680 |
| L06 | 左右对比 | 两列 808 宽，标签 + 图 | 上下两块 936×340 |
| L07 | 汇总 | `cards` 四张，2×2，每张 816×320 | 单列 4 张 936×250 |
| 细节页 | 截图 / 界面细节 | **无标题**，图铺满全屏 `f.scene.detail`（整个画面，`Shot` 设 `radius={0}`），字幕叠在图上 | 同 |

- **视频不是 PPT，留白不能多**：图在版式允许的范围里尽量大，四周只留安全区边距和字幕带，不留成片的空白；只有一句话的镜用 T01 大字撑满。
- **画面只有一张图时，用细节页铺满全屏**：截图、重绘界面、卡片都一样，不放标题，放进整个画面、去掉圆角；比例和画面不同时等比放到最大，水平、垂直都居中。字幕直接叠在图上（字幕自带描边）。`film.json` 里给这一镜标 `"full_bleed": true`，`wka qc` 就不查它的留白。
- **选版式先看图的比例**：标题 + 图（L02 / L03）的图区是扁的，16:9 截图放进去最宽只有约 1040，左右会空；单张 16:9 截图用细节页或 L04，L03 留给长条图。竖屏放 16:9 图，铺满全屏也只占满宽度，上下会空：竖屏尽量用竖构图的素材，或在 `Shot` 里推近只取一部分。
- 推近取景后，图里能看到的内容也要居中：取景框中心对准要看的内容，不让内容一侧被裁掉、另一侧空着。
- 左栏文字和右图抢地方时，先让图吃掉四周的空白；左栏宽度用母版的值，不再自己收窄，标题长了就精简文字。
- 竖屏超过约 8 个汉字的标题给 `portrait` 断行。
- 片尾前可插一镜 3.5 秒的无旁白 L07 汇总页（`f.layout.L07.cards` 按阅读顺序排好的四个位置）。

### 景别对照表

发布会式的画面靠**版式**和 `Shot` 的**取景**定景别：看一屏里同时摆了多少东西、主体被推到多近。

| 景别 | 本风格里的样子 | 怎么做到 |
|---|---|---|
| 远景 | 很多个小对象一起出现，看的是整体数量或格局，如 72 个格子、四张汇总卡 | L05 图形区、L07 汇总 |
| 全景 | 一句话撑满画面，或一张完整的界面 / 图带标题 | L01、L02、L03；`Shot` 不推近 |
| 中景 | 观点和画面并排，或左右两块对比 | L04、L06 |
| 近景 | 界面里的一个面板、一块区域占满图位 | `Shot` 用 `focusOn` 取景到一个面板 |
| 特写 | 一行字、一个按钮、一处改动铺满全屏 | 细节页 + `focusOn` 推近（`maxZoom` 2.2–3）+ `Highlight` |

## 5. 技法（对应的积木见 TECH.md）

镜头文件第一行注释按下面的名字写本镜用到的技法，如 `// s03 —— 界面与截图、形态变化`。

### 背景 → `ShotRoot`（自动）
深色透视网格 40% + 暗角，全片按片内时间极慢推进（第一分钟 6%，之后不动），跨镜连续。镜头里不用管。

### 标题 → `Headline`
整块淡入上浮 0.5 秒，不做逐字动画；`[方括号]` 上强调色。

### 要点与步骤 → `CuePoint` / `StepList` / `Callout`
要点一次只亮一条，新的一条叠化替换旧的；步骤列表高亮当前步；`Callout` 是平的强调标签，不旋转、不加粗框。

### 界面与截图 → `Shot` + `Highlight` + `Cursor`
界面在 `Shot` 里按自然尺寸画，`Shot` 负责缩放取景；高亮框描边画出（可选 spotlight 压暗四周），截图原有的红框一律去掉，高亮由代码画。静止截图加 3% 缓慢推进（`push`）。

### 形态变化 → `MorphBox`
同一个对象在两镜里形态不同：盒子移动缩放，同时旧内容叠化成新内容。

## 6. 运动语言

- 动作时长：淡入 14 帧（≈0.5 秒），移动 20 帧，转场 24 帧（0.8 秒），镜头移动 21 帧（0.7 秒），都在 0.5–0.9 秒内。出现用 expo-out（`reveal`），移动用慢进慢出（`glide`）。
- **神奇移动只做对象级**：同一个东西位置 / 大小 / 形态不同就移动缩放过去（矩形插值 + 镜头；形态变化用 `MorphBox`）；一镜的结束画面在下一镜开头出现时，导出"结束帧"组件叠在上面淡出。
- 镜头：`focusOn` 取景，padding 60–160，`maxZoom` 2.2–3，夹紧在内容内；拉远揭示时新面板在拉远一半时滑入，不出现空窗口。
- 多个窗口 / 卡片用 `pop` 逐个弹出，间隔 3–8 帧。

### 时长

沿用 `director/specs/STORYBOARD.md` 的默认值；有人声时一镜的长度跟着这一镜的旁白走（第 7 道按实测回填）。

### 转场

分镜「转场」栏写进入这一镜的接缝，对应镜头里 `SceneShell` 的 `enter`（前镜的 `exit` 要配对）。

| 名称 | 何时用 | 实现 |
|---|---|---|
| fade | 换话题（默认） | `enter/exit="fade"`；可配一声 `swish` |
| hold | 同一对象延续到下一镜，常接对象级神奇移动 | 前镜 `exit="hold"`、后镜 `enter="hold"`：画面不闪，只有文字交叉淡出，后镜从前镜最后的取景继续；交接前让前镜的叠加层（高亮框、压暗、鼠标）在最后 8 帧淡掉 |
| 硬切 | 尽量不用 | 直接切 |

硬切全片 ≤ 2 次（`style.json` 的 `qc.cuts_max`，`wka qc` 会数）。

## 7. 声音

- 分镜「音效」栏写音效名（如 `ding`）。音效用录音音效库（`sfx.json`，按场合命名：说观点 `ding`、切镜 `swish`、推近 `spring`、单击 `click`…），场合表、电平、获取与许可见 `SFX.md`。
- 音效要稀：每镜最多一个"叮"；鼠标点击只放一个单击声，不叠别的；同一拍不叠两个强调音；切镜嗖声只给 `fade` 接缝。推近时可放一声 `spring`，拉远不放。
- 音效和配乐写在片子的 `audio/build.mjs`（`sfx.place(buf, 名字, { at })`），时间点与镜头里的同步点（`s.cueIn('名')`）对齐。
- 背景音乐用 `synth.bed` 铺底，返回音轨标 `duck: true` 随人声闪避；声轨响度 -14 LUFS（`style.json` 的 `loudness`）。`wka soundtrack` 打出的音效听感审计里有被盖住的，交给用户定怎么改。见 `SFX.md`。
- 旁白按 director 的旁白环节走（自己的录音或 AI 配音）。

## 8. 禁忌清单

- ❌ **标题逐字符变形、字符之间的神奇移动**（用户否决过三次）
- ❌ 进度条
- ❌ 第二种强调色；装饰性渐变光斑
- ❌ 中文字幕折成两行（中英双语是中文一行 + 英文一行，不算）；字幕带里放按钮、步骤、要点
- ❌ 截图里保留原有红框、打码块（用代码重绘）
- ❌ 画面文字照抄旁白
- ❌ 一个大数字代替"多"
- ❌ 直接读 `s.cues` 或 `s.cueIn(变量)`（会让镜头缓存失效）

## 10. 交付前质检

`wka qc` 自动量：

- 深色底占比 ≥ 60%（`whitespace_min`，底色 `#161616` ± 24）；标了 `"full_bleed": true` 的镜头不查这一项
- 橙色 ≤ 4%（`accent_max`）
- 相邻帧差 ≤ 20，镜头切换处硬切 ≤ 2

人工看（`wka still` 接触表 + 逐帧比对接缝）。拿不准有没有出安全区、进字幕带时，临时在镜头里放一个 `<Guides />`，它会画出安全区、字幕带和出镜小窗位置，看完删掉：

- [ ] 每镜一个观点；画面文字不复述旁白
- [ ] 全片只有一种强调色
- [ ] 标题不折行、不进出镜小窗区、不进字幕带
- [ ] 只有一张图的镜，图铺满全屏、居中、标了 `full_bleed`，取景后内容没有一侧被裁
- [ ] 没有成片的空白：图都撑到了版式给的大小
- [ ] 开了出镜小窗时，小窗没有盖住高亮框、鼠标和关键文字
- [ ] hold 接缝前后两帧几乎一致
- [ ] 截图没有原有红框和打码块
