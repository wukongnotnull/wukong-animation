# 八道制作流程与历史项目只读

Source: grilling Q1–Q17、后续文案修订；PRD 提交 560404a 已获批

## 1. 问题与目标

当前引擎、工作台、交付签批按 15 道工序执行；读取进度还会自动换算旧编号。目标是只运行新的 8 道工序，旧项目只读留档，取消旧 AI 人声/字幕制作能力。新旧文件均不得因读取而被改写；不实施自动迁移。

## 2. 架构与组件边界

- `core/state.mjs` 是流程身份、步骤、审片门和旧档案保护的唯一来源。新流程使用内部数据标记 `flow: 6`，这是进度格式标识，不修改插件、引擎或流程文档的发布版本号。
- 新片创建入口在写入简报或影片文件前识别目录历史，在成功创建时记录新身份；已有旧记录的目录拒绝继续初始化。新建独立片目录可复用录音等输入素材，不能自动复制旧签批。
- 影片读取、CLI 写操作、工作台写 API、交付与批准入口都验证新项目身份。旧档案查看使用独立的只读读取路径，不调用制作、归档快照、进度换算或签批逻辑。
- 工作台的新流程目录和新交付物文案取统一定义；旧档案只列现存文件及已有账本记录，使用原存储标签与上下文，不把旧编号投射到新流程。
- 导演、入口技能、简报模板、制作规范及生成文档同步描述唯一新流程，不保留第二套可执行导演规则。

## 3. 接口、数据与行为

### 流程身份与保护

提供只读的项目检查，以及显式的新项目初始化和“可制作”断言。合法新标记可恢复制作；旧 flow 1–5、缺 flow 的历史记录以及无进度但已有简报、film.json 或制作账本的目录为历史只读。只有输入素材的目录允许创建新项目。损坏、冲突和未来标记报错，不覆盖、不降级、不自动修复。

读取历史进度返回原始历史上下文，不执行旧 `migrateProgress` 换算。制作、登记、批注、检查确认、返修、签批、运行记录写入均须在创建目录/锁文件/待批准记录之前拒绝历史项目。项目级初始化不得借此修改已有历史影片。

### 唯一新流程

| 步骤 | 名称 | 主要交付物 | 审片门 |
| --- | --- | --- | --- |
| 1 | 制作准备 | 环境检查结果 | 无 |
| 2 | 确定方案 | 方案简报 | ① |
| 3 | 编写剧本 | 剧本 | ② |
| 4 | 规划镜头 | 分镜稿 | ③ |
| 5 | 制作小样 | 小样视频 | ④ |
| 6 | 制作成片 | 成片视频 | ⑤ |
| 7 | 调整画幅 | 横屏成片／竖屏成片 | ⑥，按约定适用 |
| 8 | 导出剪映草稿 | 剪映草稿 | ⑦，按约定适用 |

新影片沿用 `brief.md`、`story.md`、`storyboard.md` 等实际文件路径，用户可见标签按上表显示。方案简报包含最终画风、配色、字体和构图，不要求独立美术文件。保留文字分镜独立审阅；分镜图与局部试样为小样阶段按需产物，不要求固定接触表或动态分镜。

制作小样保留内部声轨、镜头、拼接及质检任务与缓存；提交整片之前刷新当前混音、核查全部镜头和音画时长，不用局部视频代替完整小样。制作成片保留终版检查与主版快照保护，完成渲染不自动签批。

交付批准、画幅保护、剪映外部打开确认改用新第 6/7/8 道及其具体版本。签批摘要包含流程身份；旧档案审批保持原存储值，不生成新批准。不适用的画幅或草稿沿用方案简报的交付决定，不伪造通过。

### 历史只读界面

影片列表与报告明确 `readonly` 和历史原因。旧项目可浏览现存通用文档/图片/音视频、原有快照/批注/签批；不创建或补全工作台账本，不重新扫描后写入版本，不提供可执行旧工序。缺失旧文件显示缺失；不拿当前文件冒充旧快照。前端禁用写操作，服务端独立拒绝，直接 CLI 调用也拒绝。展示“续作请另建新项目并复用素材”，不提供隐式迁移按钮。

### 已弃用能力

删除或禁用在用入口的 AI 人声、字幕制作、导入、专用预览、烧录、外挂、主播字幕核验与剪映隐式字幕路径。旧命令返回明确的弃用提示，不执行旧实现。共享文字计数等非字幕工具移出字幕组件供声画同步使用；画面标题/题字继续保留。

## 4. 约束、兼容性与非目标

- 只维护新的八道流程，旧项目只读留档；不自动迁移、不继承旧签批。
- 不修改发布版本号、安装缓存，不自动发布或推送触发媒体 CI。
- 每批视频生成（含测试和重试）仍单独获得开始授权。
- 不新增手动剪辑器、工作台文字编辑器、在线协作或素材上传。
- 保留无关文件、工作和历史证据；不因弃用而删除用户成片、字幕或录音。

## 5. 错误处理与运维

历史只读、损坏记录、未来格式分别给出可执行提示。身份检查必须早于任何文件写入。失败不更改原记录、不创建虚假的批准；新项目的恢复只复用签名、文件及检查仍有效的成果。旧档案不需要安装旧 TTS 或字幕依赖即可查看已有结果。

## 6. 验收标准与测试

先写失败测试覆盖：新建和重开身份、仅输入素材、各种旧历史标记、损坏/未来记录、旧目录初始化拒绝；断言旧目录字节及文件清单不变。再验证工作台只读显示、所有写 API 拒绝、新项目阶段和标签、6/7/8 批准绑定与前端剪映确认。

已有单测中旧流程运行预期按已弃用需求改为拒绝/只读断言，不通过删除测试掩盖回归；仍有效的算法、素材保护和审阅测试继续执行。普通制作夹具显式创建新身份，不能把历史项目悄悄当新片。真实浏览器核对新项目与档案切换。需要生成媒体的测试集合先列批次并取得授权，静态检查和不生成视频的测试可先运行。完整验证证据另行记录，不预先声称完成。
