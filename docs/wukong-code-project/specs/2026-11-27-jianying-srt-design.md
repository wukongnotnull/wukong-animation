# 剪映草稿 SRT 字幕

2026-11-27。适用于当前制作流程的第 9 道工序。

## 导出行为

- `wka final <片目录> --formats jianying` 自动使用当前录音中已匹配或经人工确认的台词句段。句段起止加上各段录音在全片中的起点，得到草稿时间线上的位置。
- 各画幅草稿各自保存 UTF-8 的 `subtitles.srt`。导出器导入这份 SRT，在视频之上生成一条名为「字幕」的原生文本轨。字幕内容、起止和样式可在剪映继续编辑。
- 新导出的字幕默认使用剪映面板坐标 `X=0、Y=-788`。写入草稿时以画布高度换算为相对纵向位移。画布高度低于 788 时，字幕中心会落到画面底边之外。
- 毫秒时间戳以草稿实际帧长为上限。人声交叠时以各句的起止拆分区间，在同一时段内把同时说出的句子逐行写入同一字幕片段。这样一条轨道也能保留每句的起止。
- 无人声时导出视频和音频分轨。含录音时，沿用现有台词定位校验，缺失、待确认或过期的定位需要先处理。独立成片继续使用原有导出流程。
- SRT 与原生草稿一同写入和核验。重试复用完整草稿，草稿改动后的重新导出沿用现有版本保护。

## 验证

用临时影片走真实 CLI，核对 SRT 内容、原生文本轨、每条字幕的微秒位置、多人声重叠及不同画幅。核对剪映面板的默认坐标与预览。验证无人声时的草稿和回执复用。剪映桌面打开、检查和重开属于第 9 道的影片验收。

剪映专业版 11.8.0 桌面实测，1280×720 与 1920×1080 草稿的字幕面板均显示 `X=0、Y=-788`。720p 测试字幕落在画外，1080p 测试字幕完整显示。
