# 删除示范片实施计划

目标：删除当前仓库两部示范片全部内容，并解除文档与测试依赖。

架构：移除片目录及衍生画廊/基准；测试改用独立的几何图形夹具，正式风格模块保持。工作台清单只清除指定片目录及匹配会话键。

约束：不升版、不发布、不生成视频，不删除其他项目、旧发布归档或无关工作。规格见同时间戳设计文件。

1. 在性能夹具测试加入独立内置风格夹具要求，先运行确认缺失而失败，再写最小夹具；保留各管线、音效与分轨验证。
2. 精确删除两片、画廊及原基准；修改 STYLE、制作规范、贡献指南和 lint/smoke，生成 catalog/README。
3. 运行受影响的单元/集成测试、两风格静帧 smoke 与 lint；排查仍在引用目标片目录的当前源文件。
4. 停止已核实本任务服务，清理对应本机登记和会话键，恢复空工作台，实际查看；记录删除量、验证边界和收尾结果后提交。
